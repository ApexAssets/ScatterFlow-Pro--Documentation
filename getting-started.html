Installation and preferences

Install ScatterFlow, add its content library, and configure the defaults for new layers

Install the add-on Install the content pack Install the biomes Preferences

Install the add-on first, then the content pack, then the biomes. Everything is set up in Blender's Preferences.

Install the add-on

Install from Disk

In Preferences, open the Get Extensions page and choose Install from Disk from the arrow menu in its top-right corner. Pick the .zip file you downloaded.

Once it is installed, ScatterFlow is in the 3D viewport's sidebar. Press N to open it.

Requires Blender 5.2 or newer. ScatterFlow Nano needs the ScatterFlow build of Blender. It is in beta, so keep backups of your files. If Windows blocks it the first time, choose More info, then Run anyway.

Install the content pack

The content pack contains the models and textures that ScatterFlow uses.

Asset Libraries

Asset libraries are the folders ScatterFlow loads its models from.

Click the Add asset library button and pick a folder for the content pack. Then click the Install asset libraries button and choose the content pack.

Needs 7-Zip or WinRAR. The content pack is a .rar archive, which Blender cannot open on its own. If you have neither program, install 7-Zip (free) first.

Managing asset libraries

Other asset libraries are added the same way. If a library is already installed on your computer, just add its folder.

Removing a library from the list does not delete its files.

To browse these models in Blender's Asset Browser as well, see Adding the library.

When the content does not install

A part of the archive is missing. Keep both parts of the content pack in the same folder.

The archive could not be extracted. A download is probably incomplete. Download it again.

Not enough disk space. The installed content pack needs about 6 GB.

“This is a biome pack.” Install it from the Biomes section instead.

Running the install again repairs an incomplete install.

Install the biomes

Biomes are ready-made scatter setups. They use the models from the content pack, so install that first.

Biomes

Choose a folder for your biomes with the folder button in the Biomes section. Then click the Install biome packs button and choose the biome pack. The biomes then appear in the Biome Browser.

The icon next to the folder shows whether your biomes have everything they need. If it shows a warning, hover over it to see what is missing.

Updating a biome pack. The installer does not overwrite existing files. To update a pack, delete its folder first, then install the new version.

When the biomes do not appear

The icon shows a warning. Hover over it to see which asset library is missing, then add it under Asset Libraries.

“This is an asset library.” Install it from the Asset Libraries section instead.

The Biome Browser is empty. Make sure the biome folder is the one you installed into, then refresh the browser.

For GScatter environments and your own biomes, see Installing biome packs.

Preferences

The rest of the preferences are in the Settings panel. Click its header to expand it.

Defaults

  • Density 1
  • Scale 1
  • Random Scale on
  • Random Rotation on
  • Align to Surface off
  • Bounding Box off

These set how new scatter layers start: their Density and Scale, and which features are turned on. Existing layers are not affected.

Turn on Bounding Box to show new layers as boxes in the viewport, which keeps heavy scenes fast. See Optimized Mesh.

If Blender does not save preferences automatically, click the Save Preferences button in the lower-left corner.

Scene Detection (Experimental)

Refreshes the layer list when you switch scenes. It is experimental, so only turn it on if you work across several scenes.

Export, Megascans and Debug Logging

The Export and Megascans panels hold the settings for game engine export and Megascans.

Leave the Debug Logging checkbox off unless support asks you to turn it on.
