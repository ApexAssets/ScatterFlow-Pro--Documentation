Installation and preferences

Install ScatterFlow, add its content library, and configure the defaults for new layers

Install the add-on Install the content Preferences

Start by installing the add-on, then use its Content Installer to add the plants, textures, and biomes. Most of this setup takes place in Blender's Preferences, available from Edit > Preferences.

Install the add-on

Install from Disk

1. Open Edit, choose Preferences..., and select Get Extensions.

2. Click the arrow in the upper-right corner and choose Install from Disk....

3. Select the downloaded ScatterFlow .zip file. Do not extract it first.

4. Select Add-ons, search for ScatterFlow, and make sure its checkbox is enabled. Expand the entry to view its version and preferences.

5. Close Preferences. In the 3D viewport, press N to open the sidebar, then select the ScatterFlow Professional tab.

Requires Blender 5.2 or newer. To use ScatterFlow Nano, use the ScatterFlow build of Blender. Extract its folder and launch blender.exe; no installation is required. This build is in beta, so keep backups of your .blend files. On Windows, the first launch may display “Windows protected your PC.” For the ScatterFlow build you downloaded, the launch options are More info, then Run anyway.

Install the content

Content Installer

Plants, rocks, textures, and biomes are distributed separately from the add-on. Install them using the Content Installer at the top of ScatterFlow's preferences.

ScatterFlow_Pro_ContentPack.part1.rar and ScatterFlow_Pro_ContentPack.part2.rar contain the plants, rocks, and textures. They form one archive split into two parts, approximately 5.5 GB in total.
ScatterFlow_ProBiomes.zip contains the biomes.

1. Download all three files into the same folder. Leave them compressed; the installer extracts them.

2. Set Content Library Folder to the location where you want to store the installed content. Allow approximately 6 GB for the extracted files. The installer remains disabled until you select a folder.

3. Click Install Content Files and select the downloads. For the two-part archive, select either part; the installer finds the other in the same folder. You can select the archive and the biomes zip together. Supported content file formats are .zip, .rar, .gscatter, and .blend.

4. Follow the installation progress in the status bar. Extracting the main archive can take several minutes. Blender remains usable during installation, and Esc cancels the operation.

5. Check the installation list. Each entry changes from Not installed to a checkmark and Installed when ready. Once ScatterFlow Assets & Textures and ScatterFlow Biomes are installed, the biomes appear in the Biome Browser.

The same list also reports installed GScatter packs and compatibility asset libraries.

RAR extraction requires 7-Zip or WinRAR. Blender cannot extract .rar files directly. The installer uses either application if it is installed. If neither is available, it reports Extracting multi-part .rar archives needs 7-Zip (free, 7-zip.org) or WinRAR. Install 7-Zip from 7-zip.org, then run Install Content Files again.

When the content does not install

“The first part ScatterFlow_Pro_ContentPack.part1.rar is missing.” or “Part ... of the archive is missing.” Keep both parts in the same folder with their original filenames. Download any missing part again.

“... could not be extracted”: an archive part may be damaged or incomplete. Compare its size with the download page and download the affected part again.

Not enough disk space. Extraction takes place inside the Content Library Folder and requires approximately 6 GB. Downloads stored on the same drive occupy another 5.5 GB until you delete them after installation.

Assets & Textures still shows Not installed. Run Install Content Files with the original downloads. Manually copying an extracted folder into the library does not register the content as installed.

Reinstalling the same files preserves existing content and adds missing files, making it useful for repairing an incomplete installation.

Preferences

Expand Settings below the Content Installer to access the remaining preferences.

Defaults

  • Density 1
  • Scale 1
  • Random Scale on
  • Random Rotation on
  • Align to Surface off
  • Bounding Box off

These settings apply to new scatter layers only. Changing them does not affect existing layers.

Density and Scale set the initial Density and Uniform Scale values.

Random Scale, Random Rotation, and Align to Surface determine whether those features are enabled when a layer is created.

Bounding Box enables Optimized Mesh for new layers, displaying instances as boxes in the viewport. Use it when setting up scenes with heavy assets.

Click Save Preferences in the lower-left corner if Blender is not configured to save preferences automatically.

Scene Detection (Experimental)

Automatic Scene Switch Detection refreshes the System List when you switch scenes. It is the same option as Auto Refresh in the layer menu.

This feature is experimental. Enable it when you regularly work across multiple scenes and need the layer list to update automatically.

Export, Megascans and Debug Logging

The Export and Megascans panels contain settings for game engine export and Megascans installation. See the Megascans page for the installation workflow.

Debug Logging writes additional information to Blender's console. Leave it disabled unless support asks you to enable it.
