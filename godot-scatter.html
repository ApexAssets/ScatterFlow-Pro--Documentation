Godot: Scatter Layers

Adjust imported layers or regenerate their placement directly in Godot

Beta ScatterFlow Link for Godot is in early development. Features, settings, and interface elements may change between releases.

Editing scatter layers

Each imported scatter layer is a node under its SF Terrain. Use Blender Exact mode to keep the placement from Blender, or Procedural mode to regenerate the layer in Godot with editable settings.

Selecting a layer

Select a layer in the Scene tree to show its controls in the dock.

Ctrl+click to select several layers. Your changes then apply to all of them.

Mode: Blender Exact or Procedural

The Mode panel shows the instance count. Click Blender Exact or Procedural to switch between the two modes.

Blender Exact is the default. It keeps the positions from Blender and lets you thin, scale, rotate, and raise or lower them. Use it when placement needs to match Blender.

Procedural regenerates the layer in Godot, with the full scatter and mask controls. It starts close to the Blender setup, but not as an exact match.

Each mode keeps its own settings, so you can switch back and forth to compare.

Blender Exact settings. These four panels adjust the imported instances without creating new positions.

Density: Keep Ratio

Keep Ratio sets how many of the imported instances are kept. 1 keeps them all, 0.5 about half, and 0 hides them all.

Lowering it and raising it again brings back the same instances, so the layout does not shuffle.

Scale

Scale Multiplier scales every instance from its imported size. 1 keeps the Blender result.

Under Random Scale, Min and Max add random size variation on top. A wider range gives a stronger mix of sizes. Set both to 1 for no extra variation.

Rotation

Offset X, Y, and Z rotate every instance by a fixed angle. Use X or Y to lean the whole layer. These controls use Z as up, like Blender.

Random Yaw adds random turning around the upright axis, up to the set angle either way. Combined with a tilt, it makes tilted instances face different directions.

Location: Z Offset

Z Offset moves every instance up or down, in metres. Negative values sink them into the ground.

Use it to fix floating bases, lift plants that sit too low, or bury rocks slightly.

Procedural settings

Click Procedural in the Mode panel to generate the layer in Godot. Your changes show in the 3D view right away.

Surface: what to scatter on

Scatter On: lists the meshes the layer scatters on. When the list is empty, the layer uses its own terrain.

To scatter on other meshes, such as a roof or a boulder, select them together with the layer and click Add Selected. Keeping the layer selected keeps its controls in the dock. Or click Pick… to choose a node from a list.

Click Select beside a target to select it in the scene, or ✕ to remove it from the list. An empty list goes back to the layer's terrain.

Target surfaces require collision. Imported terrains already have it. For your own meshes, add a StaticBody3D with a collision shape.

Scattering: Density / m² and Density Multiplier

Density / m²: how many instances per square metre. A value of 0.03 is about one instance per 33 square metres, while grass and flowers often use 1 or higher.

Density Multiplier: scales the overall density while keeping the base value from Blender.

A top-down view makes crowded or sparse areas easier to spot.

Seed

Seed gives a different random arrangement without changing any other settings. The same seed always gives the same layout.

Minimum Distance

Minimum Distance is the smallest gap allowed between instances, in metres. Instances that would be closer are left out.

Raise it to reduce clumping and spread instances more evenly.

Max Instances

Max Instances caps the number of instances, whatever the Density. Use it to keep very large or dense layers under control.

Scale: Uniform and Non-Uniform

Uniform Scale: the overall size. 1 uses the mesh's own size.

Non-Uniform Scale X, Y, and Z: scale each axis on its own. Z is height, so raise Z for taller instances and X or Y for wider ones.

Random Scale

Turn on Random Scale to give each instance a size between Min and Max. A wider range gives more variation.

Align to Surface

Align to Surface tilts each instance to match the ground beneath it. Turn it off to keep instances upright on slopes.

Use it for rocks, grass, and ground cover. Leave it off for trees that should grow straight up.

Random Rotation

Turn on Random Rotation to vary how instances are turned, which reduces repetition. Amount X, Y, and Z set the range for each axis, in degrees.

By default only the heading around the upright axis varies. Add X or Y for random tilt.

Z Offset

Z Offset in the Rotation panel moves instances by a set distance, in metres. With Align to Surface off, they move straight up or down. With it on, they move along the tilted upright direction.

Masking: where a layer may grow

Masks limit where a layer grows, by slope, height, patterns, or distance to objects and paths. Turn a mask on with the checkbox in its title. You can combine several masks.

Slope Mask (Abiotic panel)

Max Angle: the steepest slope allowed, in degrees. Lower it to clear steep faces and keep instances on flatter ground.

Turn on Smooth Transition to soften the edge. Transition then sets how wide the fade is, in degrees.

Turn on Invert to keep instances on steep ground instead of flat ground.

Elevation Mask (Abiotic panel)

Height: the highest point instances can grow, in metres above the terrain's origin. Lower it to clear the tops of hills.

Turn on Smooth Transition to soften the height limit. Transition then sets the distance, in metres.

Turn on Invert to keep instances above the limit instead of below it.

Noise Mask

Breaks coverage into irregular patches, for plants that grow in clusters.

Scale: the patch size. Lower values give larger patches.
Detail: adds finer pattern inside the main one.
Roughness: how strong that finer detail is.
Lacunarity: how much the scale changes between detail levels.
Distortion: warps the patches into less rounded shapes.
Seed: a different pattern with the same settings.

Min and Max under Range set how sharp the patch edges are. Close values give hard edges, and a wider gap gives softer ones.

Turn on Invert to swap the patches and the gaps.

Geometry Proximity (Proximity panel)

Controls placement near chosen objects. Select them together with the layer and click Add Selected under Objects, or click Pick….

Distance: how far from the objects the mask reaches, in metres. Turn on Smooth Transition and set Transition to soften the edge.

In the Behaviour list, Repel clears instances near the objects, and Attract keeps them only near the objects. Use Repel to clear space around a house, or Attract for plants along its walls.

Curve Proximity (Proximity panel)

Uses a path to shape a region, such as a footpath or roadside planting. Add a Path3D node and draw its points in the 3D view. Then select it with the layer and click Add Selected under Curves.

Distance, Smooth Transition, Transition, and Behaviour work as in Geometry Proximity, measured from the path.

Infinite Height measures distance sideways only, ignoring height. Turn it on when the path sits above the terrain. Without it, raising the path can shrink or remove its effect.

Paths remain editable. Moving their points updates the layer.

Meshes

Choosing what the layer scatters

The Meshes panel lists the meshes the layer scatters. In Blender Exact it shows how many instances each mesh has. You can change the list in Procedural mode.

Weight: how often a mesh is picked compared with the others. 0 leaves it out.

Click + Selected Nodes to add meshes from the selected nodes, with their materials.

Click + FileSystem to add meshes or model files selected in the FileSystem dock, such as .glb, .gltf, .fbx, .obj, or .tscn scenes.

Click ✕ to remove a mesh from the layer.

Re-exporting replaces the mesh list. Exporting from Blender again brings back Blender's mesh list.
