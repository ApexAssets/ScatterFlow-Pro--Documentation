Godot: Scatter Layers

Adjust imported layers or regenerate their placement directly in Godot

Beta ScatterFlow Link for Godot is in early development. Features, settings, and interface elements may change between releases.

Editing scatter layers

Each imported scatter layer is a node beneath its SF Terrain in the Scene tree. Use Blender Exact to preserve the imported placement, or Procedural to generate the layer in Godot using editable distribution settings.

Selecting a layer

Select the layer in the Scene tree, such as Field Trees beneath SF Terrain - Field. The dock switches to its controls and displays a label such as Editing Field Trees.

Ctrl+click to select multiple layers. Setting changes apply to every selected layer.

Mode: Blender Exact or Procedural

The Mode panel displays the instance count and active mode. Click Blender Exact or Procedural to switch.

Blender Exact is the default. It preserves Blender's exported positions and provides adjustments for thinning, scale, rotation, and height. Use it when placement needs to match Blender.

Procedural regenerates the layer in Godot and provides the full scatter and mask controls below. Its starting values approximate the Blender setup, so the initial appearance is similar rather than an exact match.

Each mode retains its settings when you switch, allowing you to compare them without losing adjustments.

Blender Exact settings. The following four panels adjust imported instances without generating new positions.

Density: Keep Ratio

Keep Ratio sets the proportion of imported instances retained. At 1, every instance remains; 0.5 keeps approximately half; 0 hides them all.

Thinning is consistent: reducing and restoring the value does not shuffle the layer's positions or randomly choose a new subset each time.

Scale

Scale Multiplier scales every instance relative to its imported size. A value of 1 preserves the Blender result.

Under Random Scale, Min and Max add random size variation on top of the multiplier. Set both to 1 for no additional variation.

For example, a range of 0.3–2.5 produces a much wider mix of small and large instances than the original sizes.

Rotation

Offset X, Y, and Z rotate every instance by the specified angles. These ScatterFlow controls use Z as up, matching Blender. Use an X or Y offset to lean an entire layer.

Random Yaw adds random rotation around the upright axis, up to the specified angle in either direction.

Combining a fixed tilt with Random Yaw varies the direction in which tilted instances face.

Location: Z Offset

Z Offset moves every instance vertically in metres. Positive values raise instances; negative values embed them in the ground.

Use it to correct floating bases, lift plants that sit too low, or make rocks appear embedded.

Procedural settings

Switch to Procedural to generate the layer in Godot. Changes update in the 3D view immediately. Click panel titles to expand the settings you need.

Surface: what to scatter on

Scatter On: lists the target meshes. When the list is empty, the layer uses its own terrain.

To use other surfaces, select their meshes together with the layer in the Scene tree or 3D view, then click Add Selected. Keeping the layer selected leaves its controls visible. Use this to move coverage onto a roof, boulder, or another mesh.

Select beside a target selects it in the scene. ✕ removes it from the target list. Clearing the list restores scattering on the layer's terrain.

Pick… opens Select a Node. Filter by name, choose the node, and click OK to add it.

Target surfaces require collision. Imported terrains already include it. For your own meshes, add a StaticBody3D with a collision shape.

Scattering: Density / m² and Density Multiplier

Density / m²: the number of instances per square metre. A value of 0.03 is approximately one instance per 33 square metres. Grass and flowers often use values of 1 or higher.

Density Multiplier: adjusts the overall density without replacing the base value imported from Blender.

Use a top-down view to compare coverage and identify crowded or sparse areas.

Seed

Seed selects a different random arrangement. With the same settings, the same seed reproduces the same layout. Change it to try new placements without changing density or other controls.

Minimum Distance

Minimum Distance sets the minimum spacing between instances in metres. Instances that would be too close to another are excluded.

Increase it to reduce clustering. For example, changing it from 0 to 4 m spreads a dense tree layer into a more evenly spaced arrangement.

Max Instances

Max Instances caps the final instance count regardless of Density. Use it to limit very large or dense layers. For example, a value of 1000 allows no more than 1000 instances.

Scale: Uniform and Non-Uniform

Uniform Scale: the overall instance size. A value of 1 uses the source mesh's size.

Non-Uniform Scale X, Y, and Z: scales each axis independently. These controls use Z for height, so increase Z for taller instances and X or Y for greater width.

Random Scale

Enable Random Scale to assign each instance a factor between Min and Max. A wider range produces stronger size variation; for example, 0.4–2 creates a mix of much smaller and larger trees.

Align to Surface

Align to Surface makes each instance stand perpendicular to the ground beneath it. Disable it to keep instances vertical on slopes.

Use surface alignment for rocks, grass, and ground cover. Keep it disabled for trees that should grow upright rather than lean with the terrain.

Random Rotation

Random Rotation varies instance orientation. Amount X, Y, and Z set the rotation ranges in degrees. The default varies headings around the upright axis to reduce repetition.

Add X or Y variation for random tilt. Toggle the setting to compare the varied result with the original orientations.

Z Offset

Z Offset in the Rotation panel moves instances by the specified distance in metres. With Align to Surface disabled, movement is vertical. With it enabled, the offset follows the surface-aligned upright direction.

Masking: where a layer may grow

Masks restrict placement by slope, height, patterns, or proximity to objects and paths. Enable a mask with the checkbox in its title and expand the title to edit it. Multiple masks can be combined.

Slope Mask (Abiotic panel)

Max Angle: the steepest allowed slope, in degrees. Lower it to clear steep faces and retain instances on flatter ground.

Smooth Transition: softens the slope boundary. Transition sets the width of the fade in degrees.

Invert: keeps instances on steep surfaces instead of flat areas.

Elevation Mask (Abiotic panel)

Height: the upper placement limit in metres above the terrain's origin. Lower it to remove instances from the upper parts of a hill.

Smooth Transition and Transition: soften the height boundary over the specified distance in metres.

Invert: keeps instances above the height limit instead of below it.

Noise Mask

Breaks coverage into irregular patches, useful for vegetation that grows in clusters.

Scale: pattern frequency. Lower values produce larger patches.
Detail: adds finer patterns within the main pattern.
Roughness: the strength of that finer detail.
Lacunarity: the change in scale between successive detail levels.
Distortion: warps the pattern into less rounded shapes.
Seed: a different pattern using the same settings.

Min and Max under Range control the transition between populated areas and gaps. Values close together give sharper boundaries; a wider interval produces softer transitions.

Invert: exchanges the populated areas and gaps.

Geometry Proximity (Proximity panel)

Controls placement near selected objects. Select the targets together with the layer and click Add Selected under Objects, or use Pick….

Distance: the affected distance from the objects, in metres.

Smooth Transition and Transition: soften the boundary.

Behaviour: Repel clears instances near the targets, while Attract keeps instances only near them. Use Repel for clearance around a house or Attract for plants along its walls.

Curve Proximity (Proximity panel)

Uses a path to define a continuous region, such as a footpath or roadside planting. Add a Path3D through Add Node > Path3D, draw its points in the 3D view, and select it together with the layer. Click Add Selected under Curves.

Distance, Smooth Transition, Transition, and Behaviour work as they do for Geometry Proximity, with distance measured from the path.

Infinite Height ignores the path's vertical distance and measures only sideways. Enable it to keep a consistent exclusion strip when a path is raised above the terrain. Without it, moving the path upward can narrow or remove its influence.

Paths remain editable. Move their points to update the layer's distribution.

Meshes

Choosing what the layer scatters

The Meshes panel lists the layer's source meshes. Blender Exact displays each mesh's instance count. Procedural mode allows changes to the mesh list.

Weight: how often a mesh is chosen relative to the others. Set it to 0 to exclude a mesh from placement.

+ Selected Nodes: adds meshes from nodes selected in the Scene tree or 3D view, including material assignments on those nodes.

+ FileSystem: adds selected mesh resources or model files from the FileSystem dock. Supported sources include .glb, .gltf, .fbx, .obj, and .tscn scenes.

✕: removes a mesh from the layer.

Re-exporting replaces the mesh list. A new export from Blender restores the source list from Blender.
