Optimization

Improve scene responsiveness and control which optimizations affect the final render

Viewport Density Optimized Mesh Camera Culling Occlusion Culling Decimator ScatterFlow Nano

Display in the viewport

These settings simplify viewport display while you work with heavy layers.

Decrease Viewport Density

  • Default off
  • Viewport Density 10%

Displays a percentage of the layer's instances in the viewport. At Viewport Density 10%, approximately one in ten instances is shown.

Use it for dense layers such as grass, where a reduced preview is enough to evaluate placement.

Optimized Mesh

  • Default off
  • Type Bounding Box

Replaces detailed viewport meshes with simpler representations. Choose the representation under Type.

Bounding Box: displays a box matching each object's bounds.
Convex Hull: displays a simplified shell that follows the object's outline more closely.
Proxy Object: uses a chosen mesh, such as a cone, cube, or icosphere. Select it under Proxy Object and adjust its size with Proxy Scale.
Points: represents each object as a point cloud. Point Radius controls point size, and Point Density controls the number of points.

Enable Bounding Box in the add-on preferences to start new layers with this optimization active.

Camera Culling

Excludes instances outside the scene camera's view. The retained region follows the camera as it moves or rotates.

FOV and Clipping

  • Default off
  • Width / Height 1.2
  • Clip Start 5 m
  • Clip End 100 m

Enable Camera Culling to restrict the layer to the camera's view and clipping range.

Width and Height adjust the retained region relative to the camera frame. A value of 1 matches the frame. The default of 1.2 adds a margin to help retain instances and shadows near its edges.

Clip End excludes instances beyond the specified distance. Clip Start excludes instances closer than the specified distance.

Camera Culling also affects renders. Excluded instances are absent from the final render, not just the viewport. Use a generous margin, especially with a moving camera.

Distance Culling

  • Default off
  • Reduction Rate 1.0
  • Seed 0

Reduces instance density with distance from the camera. This option is part of Camera Culling.

Reduction Rate controls the amount of thinning. Seed changes which instances are excluded. The effect can be subtle and is most visible in distant areas of the layer.

Occlusion Culling

Occlusion Culling

  • Default off

Excludes instances hidden behind other objects from the scene camera's viewpoint. Enable the option and select a Collection containing occluding objects, such as buildings, walls, rocks, or hills.

The excluded area updates as the occluding objects move. For example, moving a wall changes which trees behind it are culled.

Camera Culling may also be required. In the documented tests, Occlusion Culling only affected the layer when Camera Culling was enabled. If it has no visible effect, enable Camera Culling as well.

Decimator

Reduces polygon counts on the source objects in a collection. Because instances share those source meshes, the reduction applies throughout the scatter.

Decimator

Expand Decimator, select the source Collection, and click Add To All to add a Decimate modifier to each object.

Master Ratio sets the proportion of geometry retained across the collection. A value of 1 keeps the original detail; 0.2 keeps one fifth. The 25%, 50%, and 75% buttons provide preset ratios. Wireframe display can help you inspect the reduction.

The buttons beside Global Decimation control viewport visibility, render visibility, permanent application with the checkmark, and removal with the cross. To simplify editing without reducing final detail, enable the reduction in the viewport and disable it for renders.

Collection Objects lists the source objects, their polygon counts, and individual Ratio controls. Use these to retain more detail on assets that need it.

ScatterFlow Nano

Beta ScatterFlow Nano and the ScatterFlow build of Blender are in beta. Keep backup copies of your .blend files before opening them in this build and while working with it.

Nano is available in the ScatterFlow build of Blender. It adjusts the viewport detail of scatter instances according to their size on screen, reducing the geometry drawn for dense scenes. It works on ScatterFlow layers in Solid shading, with or without textures, and does not affect renders.

The recorded comparison uses Desert_V2 on a 30 m square surface, with approximately 920,000 instances and 17 billion polygons.

Before and after

The comparison shows the same scene with Nano disabled and enabled. Frame duration reflects the actual viewport redraw time, and the on-screen readout reports performance.

Without Nano, redraws took approximately 1.9 seconds, or about 0.5 frames per second. With Nano enabled using the button at the right end of the viewport header, redraws took approximately 55 milliseconds, or 18 frames per second: about 35 times faster in this test.

Performance depends on the scene and hardware. Treat these measurements as an example rather than an expected speedup for every project.

The Nano panel

Click the arrow beside the Nano button to open its panel. The main button toggles Nano and displays Nano: Activated or Nano: Deactivated. Other settings are disabled while Nano is off. The enabled state is remembered between sessions.

Visualizer displays diagnostic colours. Clusters shows the triangle groups used to draw each object, Detail shows the chosen detail levels, and Instances gives each instance a separate colour. Return it to Off for normal display.

Detail Level

  • Default 1 px
  • Range 0.25 to 8 px

Sets the maximum allowed difference from the full mesh, measured on screen in pixels. Lower values retain more detail. Higher values reduce detail and improve performance.

Higher values can remove fine details such as leaves, making branches more prominent. Use the Clusters visualizer to inspect how the detail changes.

Reduce Small Objects

  • Default 0 px
  • Range 0 to 16 px

Reduces the number of instances drawn below the specified screen size. Smaller instances are reduced more strongly. At 0, all instances are drawn.

Increase this value to reduce distant pebbles and small plants that contribute little visible detail.

Recorded in ScatterFlow 1.0.9 on the ScatterFlow build of Blender 5.2.2, using the assets bundled with the add-on.
