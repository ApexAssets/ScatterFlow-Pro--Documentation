Optimization

Improve scene responsiveness and control which optimizations affect the final render

Viewport Density Optimized Mesh Camera Culling Occlusion Culling Decimator ScatterFlow Nano

Display in the viewport

These settings make heavy layers lighter to display while you work.

Decrease Viewport Density

  • Default off
  • Viewport Density 10%

Shows only part of the layer's instances in the viewport. Viewport Density sets how many: at 10%, about one in ten is shown.

Use it on dense layers such as grass, where a thinner preview is enough to judge placement.

Optimized Mesh

  • Default off
  • Type Bounding Box

Shows simple stand-ins instead of the full meshes in the viewport. Pick one from the Type list.

Bounding Box: a box around each object.
Convex Hull: a simple shell that follows the object's shape more closely.
Proxy Object: a mesh of your choice, such as a cube or cone. Pick it in the Proxy Object field. Proxy Scale sets its size.
Points: a cloud of points. Point Radius sets their size, and Point Density how many there are.

To start new layers with Bounding Box on, turn it on in the add-on preferences.

Camera Culling

Removes instances outside the scene camera's view. The kept area follows the camera as it moves and turns.

FOV and Clipping

  • Default off
  • Width / Height 1.2
  • Clip Start 5 m
  • Clip End 100 m

Turn on Camera Culling to keep only the instances inside the camera's view and clipping range.

Width and Height size the kept area relative to the camera frame. At 1, it matches the frame. The default of 1.2 adds a margin, so instances and shadows near the edges are kept.

Clip Start removes instances closer than its distance, and Clip End removes those further away.

Camera Culling also affects renders. Removed instances are missing from the final render too, not just the viewport. Use a generous margin, especially with a moving camera.

Distance Culling

  • Default off
  • Reduction Rate 1.0
  • Seed 0

Thins out instances the further they are from the camera. It is part of Camera Culling.

Reduction Rate sets how much they are thinned, and Seed changes which ones are removed. The effect can be subtle and shows most in the distance.

Occlusion Culling

Occlusion Culling

  • Default off

Removes instances hidden behind other objects, as seen from the scene camera. Turn it on and pick a collection in the Collection field. It should hold the objects that block the view, such as buildings, walls, rocks, or hills.

The hidden area updates when those objects move.

Camera Culling may also be required. Occlusion Culling may only work while Camera Culling is on. If it has no effect, turn on Camera Culling as well.

Decimator

Lowers the polygon count of the source objects in a collection. Every instance uses those source meshes, so the whole scatter gets lighter.

Decimator

In the Decimator section, pick the source collection in the Collection field and click the Add To All button. This adds a Decimate modifier to each object.

Master Ratio sets how much geometry is kept across the collection. At 1, the original detail is kept; at 0.2, one fifth. The 25%, 50%, and 75% buttons are quick presets.

The buttons next to Global Decimation turn the reduction on or off in the viewport and in renders, apply it permanently (checkmark), or remove it (cross). To keep editing fast without losing render detail, turn it on for the viewport and off for renders.

The Collection Objects list shows each source object with its polygon count and its own Ratio, so you can keep more detail on the assets that need it.

ScatterFlow Nano

Beta ScatterFlow Nano and the ScatterFlow build of Blender are in beta. Keep backup copies of your .blend files before opening them in this build and while working with it.

Nano is part of the ScatterFlow build of Blender. It lowers the viewport detail of instances based on how large they are on screen, so dense scenes draw much faster. It works on ScatterFlow layers in Solid, Material Preview, and EEVEE Rendered mode, and does not affect final renders.

Before and after (Solid)

Turn Nano on with the button at the right end of the viewport header.

In a dense desert biome with close to a million instances, the viewport redrew about 35 times faster with Nano on. Results depend on your scene and hardware.

Material Preview

Nano also works in Material Preview, with full materials, including displacement.

In the same desert scene, the viewport went from about 0.2 to 5.5 frames per second.

It also uses less memory here, because images are kept only on the graphics card once loaded.

EEVEE Rendered mode

With EEVEE as the render engine, Nano also works in Rendered viewport shading, including shadows. In the same scene, redraws went from about 6.3 seconds to under a fifth of a second.

Final renders, and Cycles in Rendered viewport shading, always use the full meshes.

The Nano panel

Click the arrow next to the Nano button to open its panel. The main button turns Nano on and off, and the other settings only work while it is on. Nano stays on or off between sessions.

The Visualizer setting shows diagnostic colours. Clusters shows the triangle groups each object is drawn with, Detail shows the detail levels in use, and Instances gives each instance its own colour. Set it back to Off for normal display.

In Material Preview and Rendered mode, the Visualizer only shows while Viewport Overlays are on.

Detail Level

  • Default 1 px
  • Range 0.25 to 8 px

Sets how far the drawn mesh may differ from the full mesh, in pixels on screen. Lower values keep more detail. Higher values are faster.

High values can remove fine details such as leaves, leaving the branches more visible. Use the Clusters visualizer to check the result.

Reduce Small Objects

  • Default 0 px
  • Range 0 to 16 px

Draws fewer of the instances that are smaller than this size on screen. The smaller they are, the more are skipped. At 0, every instance is drawn.

Raise it to thin out distant pebbles and small plants that add little visible detail.

Recorded in ScatterFlow 1.0.9 on the ScatterFlow build of Blender 5.2.2, using the assets bundled with the add-on.
