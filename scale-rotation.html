Scale and Rotation

Adjust instance size, orientation, and variation

Scale Rotation

Scale

Scale has three controls that you turn on separately: overall size, size per axis, and random variation. Their values multiply, so you can use them together.

Uniform Scale

  • Default on, 1.0

Scales every instance by the same amount. 1 keeps the object's original size, 2 doubles it, and 0.5 halves it.

Turn it off to remove its effect without losing the value.

The starting value for new layers is set in the add-on preferences.

Non-Uniform Scale

  • Default off, 1 / 1 / 1

Scales instances separately along X, Y, and Z. Raise Z to make objects taller, or change X and Y to change their width.

Use it for taller grass or flatter rocks without editing the original mesh.

Random Scale

  • New layers on
  • Min 0.6
  • Max 1
  • Seed 0

Gives each instance a random size between Min and Max, as a multiple of the original size.

Lower Min for more variation; values near 0 give many very small instances. Set Max above 1 to allow instances larger than the original.

The Random Scale checkbox in the preferences sets whether new layers start with it on; see Defaults.

Seed changes which instances get which size, without changing the range.

Group Scale

When you select a group, Group Scale takes the place of the Scale section. Its Uniform Scale applies to every layer in the group.

Rotation

Rotation combines a fixed rotation, alignment to the surface, and random variation. These controls work on single layers, not groups.

Rotate

  • Default off, 0° / 0° / 0°

Rotates every instance by the same amount around X, Y, and Z. Z turns its heading; X and Y tilt it.

Use it to fix an object that faces the wrong way, or to lean a whole layer in one direction.

Random Rotation

  • Default Amount 0 / 0 / 1
  • Seed 0

Gives each instance a different random rotation. The three Amount values set how much it varies around X, Y, and Z.

The default spins instances freely around Z and keeps them upright, which suits most plants. Add X and Y for rocks or debris that should tilt in any direction.

Seed gives a different set of rotations. The add-on preferences set whether new layers start with Random Rotation on.

Snap

  • Default off
  • Max Angle 90°

Limits Random Rotation to steps of Max Angle. Which step each instance gets is still random.

At 90° instances face one of four directions, at 45° one of eight, and at 180° one of two. Use it for objects that should stay neatly lined up, such as crates, paving, or planks.

Align to Surface

  • Default set in preferences
  • Alignment Strength 1.0

Tilts each instance to match the surface under it, so on a slope it leans with the ground.

Alignment Strength blends from upright at 0 to fully aligned at 1. Around 0–0.3 suits trees that should stay mostly upright. 1 suits grass, rocks, and anything that should follow the ground closely.
