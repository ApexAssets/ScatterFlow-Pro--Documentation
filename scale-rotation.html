Scale and Rotation

Adjust instance size, orientation, and variation

Scale Rotation

Scale

The Scale section combines three independently enabled controls: overall scale, per-axis scale, and random variation. Their values multiply together, so you can use them at the same time.

Uniform Scale

  • Default on, 1.0

Scales every instance by the same factor. A value of 1 preserves the source object's size, 2 doubles it, and 0.5 halves it.

Disable Uniform Scale to remove its effect without losing the stored value.

The starting value for new layers is set in the add-on preferences.

Non-Uniform Scale

  • Default off, 1 / 1 / 1

Scales instances independently along X, Y, and Z. Increase Z to make objects taller, or adjust X and Y to change their width.

Use it to create variations such as taller grass or flatter rocks without modifying the source mesh.

Random Scale

  • New layers on
  • Min 0.6
  • Max 1
  • Seed 0

Assigns each instance a random scale between Min and Max.

New layers start with a range of 0.6 to 1 times the source size. Lower Min for stronger variation; values near 0 produce many very small instances. Set Max above 1 to allow instances larger than the source object.

Whether new layers start with Random Scale enabled is set by the Random Scale preference; see Defaults.

Seed changes which instances receive each size without changing the range.

Group Scale

When a group is selected, Group Scale replaces the layer's Scale section. Its Uniform Scale applies to every layer in the group.

Rotation

Rotation combines a fixed rotation, alignment to the surface, and random variation. These controls are available for individual layers, not groups.

Rotate

  • Default off, 0° / 0° / 0°

Rotates every instance by the same amount around X, Y, and Z. Z changes its heading, while X and Y add tilt.

Use it to correct the orientation of a source object or lean an entire layer in one direction.

Random Rotation

  • Default Amount 0 / 0 / 1
  • Seed 0

Applies a different random rotation to each instance. The three Amount values control variation around X, Y, and Z.

The default allows free rotation around Z while keeping instances upright. This suits most plants. Add X and Y variation for objects such as rocks or debris that should tilt in several directions.

Seed generates a different set of rotations.

Whether Random Rotation starts enabled on new layers is determined by the add-on preferences.

Snap

  • Default off
  • Max Angle 90°

Restricts Random Rotation to increments of Max Angle while keeping the choice of direction random.

At 90°, instances face one of four directions; at 45°, one of eight; and at 180°, one of two. Use it for objects that should retain regular alignment, such as crates, paving, or planks.

Align to Surface

  • Default set in preferences
  • Alignment Strength 1.0

Tilts each instance to stand perpendicular to the surface beneath it. On a slope, this makes the instance lean away from vertical to match the ground.

Alignment Strength blends between upright at 0 and fully surface-aligned at 1. Values around 0–0.3 are useful for trees that should remain mostly vertical. A value of 1 suits grass, rocks, and objects that should follow the ground closely.
