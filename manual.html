Manual Mode

Place and edit instances directly with nine brushes

Starting Scatter Manager Controls Placing brushes Editing brushes Groups

Starting Manual Mode

Use Manual Mode for placements that need direct control, such as a hero tree, vegetation along a path, or the edge of a clearing. Set the layer's Scattering Type to Manual to display the Manual Mode section. See Scattering Type for a comparison with Procedural mode.

Start Placing and the mode dials

Click Start Placing to display the numbered brush dials on the left of the viewport. A shortcut card appears beneath them.

Select a brush by clicking its dial or pressing its number, 1–9. The selected dial remains visible with its settings, while the other dials collapse. Click the active dial again to display the full brush list. No instances are placed until a brush is selected.

Press Esc, Enter, or the right mouse button to leave Manual Mode. Your placements remain on the layer.

Scatter Manager

Control which source objects the placement brushes can use.

Scatter Manager

The list shows the objects assigned in the layer's Instances section, along with their polygon counts. Disable an object's checkbox to exclude it from new placements. For example, disable rocks and bushes to paint only the trees in a mixed collection.

All enables every object; None disables them all.

Enable at least one object. Start Placing cannot begin when every object is disabled.

Controls shared by every brush

Erase and brush size

Hold Ctrl and drag to erase instances. The brush ring turns red while erasing. There are two exceptions: with Scale, Ctrl shrinks instances; with Attract, it pushes them away.

Hold F and move the mouse horizontally to adjust the brush size. This changes the same value as the Radius dial.

Viewport navigation with the middle mouse button and mouse wheel remains available while painting.

Using the setting dials

Drag a dial horizontally to change its value. Hold Shift for finer adjustments, or use the mouse wheel while hovering over the dial.

Ctrl+click or double-click resets a dial to its default. Click an on/off dial to toggle it.

Every brush has a Radius control. The default is 2.0, except for Precision, which uses 0.7.

Placing brushes

1  Area

  • Density 1
  • Delay 1.00
  • Surface Rotation on

Places random instances within the brush area as you drag.

Density sets how many instances each step of the stroke adds. Increase it for denser coverage.

Delay controls the distance between placement steps, not the time between them. Lower values create a continuous band; higher values produce separated clusters.

Surface Rotation aligns new instances to the slope beneath them. Disable it to keep them upright.

2  Precision

  • Scale 1.00
  • Mesh Preview on

Places one instance at a time. A transparent preview follows the cursor. Press and drag to position the instance, then release to place it.

Scale sets the size of the next instance.

Swap Preview, or F8, switches to another enabled object from the layer. This is available when the layer uses a collection with more than one object enabled in Scatter Manager.

Mesh Preview toggles the transparent object preview. When disabled, the cursor shows a simple ring.

3  Align

  • Density 1
  • Delay 1.00
  • Surface Rotation on

Places instances like Area, but rotates each one to face along the brush stroke. Use it for directional arrangements such as fences, logs, hedges, or crop rows.

Density, Delay, and Surface Rotation work as they do for Area. Their values are stored separately for Align.

Editing brushes

These brushes modify existing hand-placed instances on the active layer. They do not affect instances on other layers.

4  Move

  • Adjust Normals off

Press over a group of instances and drag to move them across the surface. The brush picks up the instances inside its radius at the start of the drag.

Set Radius large enough to include the entire group before moving it.

Adjust Normals realigns moved instances to the slope at their new position.

5  Scale

  • Scale Speed 0.05

Hold the mouse button over instances to enlarge them. Hold Ctrl to shrink them instead. Scaling continues while the button is held, so use short presses for controlled adjustments.

Scale Speed controls how quickly instances grow or shrink.

6  Rotate

  • Jitter 0.10

Adds random tilt to instances under the brush. The effect builds while the brush remains over them. Use it to break up an arrangement that looks too uniform.

Jitter sets the amount of tilt added at each step.

7  Dilute

  • Probability 0.10
  • Min Distance 0.70

Thins crowded areas by removing instances that are too close to their neighbours.

Min Distance sets the target spacing. Instances closer together than this may be removed.

Probability sets the chance of removing each eligible instance on a brush pass. Lower values thin the layer gradually over repeated strokes; higher values remove more at once.

8  Attract

  • Pull Speed 0.03
  • Adjust Normals off

Hold the mouse button to pull instances inside the brush toward the cursor. Holding longer forms a tighter cluster; eventually, all affected instances can converge on the same point.

Hold Ctrl to push instances away instead. They move toward the edge of the brush and stop there, making this useful for opening a clearing. Increase Radius to affect a larger area.

Pull Speed controls how quickly instances move.

Adjust Normals realigns instances to the surface as they move.

9  Comb

  • Rotate Speed 0.015

Leans instances in the direction of the brush stroke. Use it to flatten grass or give trees a directional, wind-blown appearance.

Rotate Speed controls how strongly each brush movement changes their lean.

Manual Mode on a group

Select a group and set its Type to Manual to paint its layers together. Group painting adds a Group Spread control for the spacing between layers around the brush. See Group Scattering for details.
