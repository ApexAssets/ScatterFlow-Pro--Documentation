Dynamics

Animate layers with wind, transition effects, and object interaction

Wind Transition Effects Collision

Dynamics adds movement over time. Play Blender's timeline to preview it.

Wind

Makes a layer's instances sway. Wind is off on new layers.

Wind Type

  • Default No Wind

Wind-Performance is the fastest. It tilts and rocks each instance as a whole.

Wind-Semi-Realistic adds waves of wind moving across the layer. It balances detail and speed.

Wind-Realistic bends plants along their height and adds fine flutter. It gives the most detailed motion but is the slowest, so save it for layers seen up close.

Adjust Strength to the scale of your assets. Wind moves instances by a set distance in the scene, so a value that suits a large tree can bend small plants too far. Lower Strength if plants bend too much or lie flat.

Main settings

  • Direction 0°
  • Strength 2
  • Speed 1
  • Scale 2

Direction sets the compass direction the wind blows toward. Strength sets how far instances are pushed, and Speed how fast they sway.

Scale sets the size of the gusts. Lower values make large areas move together. Higher values make neighbouring instances move more differently.

Wind-Performance also has Smoothness, which softens the motion.

Wind-Realistic extras

  • Bending 1
  • Minor Wind on, 1

Bending sets how much a plant curves along its height instead of tilting stiffly.

The Enable Minor Wind checkbox adds finer motion on top of the main sway. Minor Wind Strength sets how strong it is.

In the Advanced panel, Height Falloff and Width Falloff control the effect from base to tip and from centre to edge. A Vertex Group can limit the effect to part of the mesh.

Presets

  • Presets Gentle Breeze, Windy, Storm

Pick a preset from the Preset list and click the Apply Preset button to set Strength, Speed, and Scale for the current Wind Type. Use it as a starting point, then fine-tune it for your assets.

Gentle Breeze is a light sway, Windy is stronger, steady movement, and Storm gives heavy leaning and gusts.

Presets differ between Wind Types, so apply the preset again after changing the type.

Wind Bake: before and after

Wind is calculated on every frame, which can slow playback on dense layers. The Bake Wind button stores the animation, so Blender only has to play it back.

In one test with thousands of trees, playback went from about 3 to 30 frames per second after baking. Your results depend on the scene.

Click the Animation button to bake the whole frame range, or Still for the current frame only. The bin icon deletes the bake.

Save first and bake after final adjustments. The bake is saved next to your .blend file. If you change the wind settings, density, or frame range, delete the bake and bake again.

Transition Effects

Animate a layer appearing or disappearing over a range of frames. There are twenty presets, and they all share the same Animation settings.

Preset

  • Default No Effect

Pick an effect from the Preset list and play the timeline. For example:

Popup: instances appear in a wave across the layer.
Radial: the layer grows out from its centre.
Vortex: instances spin down into place.
Rain: instances fall into place from above.

The other presets, such as Ripple, Geyser, and Bloom, work the same way.

Animation settings

  • Start Frame 1
  • End Frame 60 to 90
  • Reverse off
  • Seed 0

Start Frame and End Frame set when the transition starts and when the layer is fully visible. A shorter range makes the effect faster, and a later Start Frame delays it.

Turn on Reverse to play the transition backward, so the full layer animates out.

Seed changes the order in which instances appear.

Each preset also has an Effect Settings panel with its own controls, such as Edge Width for Radial.

Collision

Flattens instances near an object, such as grass under a ball, foot, or wheel.

Collision Object and Distance

  • Default off
  • Min 0
  • Max 0.2

Turn on Collision and pick an object in the Collision Object field. Instances near it bend down, then spring back when it moves away.

Max sets how far the effect reaches from the object. The default only reaches the area right around it, so raise it to flatten a wider area.

Min is the distance within which instances are completely flat. Between Min and Max, they are partly flattened.

Group Dynamics

Select a group to open Group Dynamics. Its settings apply to every layer in the group, so a whole planting moves the same way.
