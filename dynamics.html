Dynamics

Animate layers with wind, transition effects, and object interaction

Wind Transition Effects Collision

Dynamics controls movement over time. Play Blender's timeline to preview these effects.

Wind

Adds swaying motion to a layer's instances. Wind is disabled on new layers.

Wind Type

  • Default No Wind

Wind-Performance has the lowest processing cost. It tilts and rocks each instance as a whole.

Wind-Semi-Realistic adds waves of wind moving across the layer, providing a balance between motion detail and performance.

Wind-Realistic bends plants along their height and adds finer flutter. It provides the most detailed motion and has the highest processing cost, indicated by a warning in the menu. Reserve it for layers that need close-up detail.

Select a type to display its settings.

Adjust Strength to the scale of your assets. Wind moves instances by a distance in the scene, so a value that suits a 10 m tree may bend small plants too far. Lower Strength if plants bend excessively or collapse flat.

Main settings

  • Direction 0°
  • Strength 2
  • Speed 1
  • Scale 2

Direction sets the compass direction the wind blows toward.

Strength controls how far instances are pushed.

Speed controls how quickly instances sway.

Scale controls gust size. Lower values make larger areas move together; higher values create more variation between neighbouring instances.

Wind-Performance also includes Smoothness to soften the motion.

Wind-Realistic extras

  • Bending 1
  • Minor Wind on, 1

Bending controls how much a plant curves along its height rather than tilting as a rigid object.

Enable Minor Wind adds finer motion on top of the main sway. Adjust Minor Wind Strength to control its intensity.

The Advanced panel contains Height Falloff and Width Falloff, which control the effect from base to tip and from centre to outer edges. A Vertex Group can limit the effect to part of the mesh.

Presets

  • Presets Gentle Breeze, Windy, Storm

Choose a Preset and click Apply Preset to set Strength, Speed, and Scale for the selected Wind Type. Use the result as a starting point, then refine it for your assets.

Gentle Breeze provides light swaying, Windy creates stronger continuous movement, and Storm produces pronounced leaning and gusts.

Preset values differ between Wind Types. Apply the preset again after changing the type.

Wind Bake: before and after

Wind is recalculated on every frame, which can slow playback on dense layers. Bake Wind stores the animation so Blender can play the cached result rather than calculate it again.

In the recorded test, approximately 7,000 trees using Wind-Realistic played a 48-frame sequence at about 3 frames per second before baking and 30 frames per second afterward. The bake took 16 seconds. These figures describe that test, not a guaranteed playback speed.

Choose Animation to bake the scene's full frame range, or Still to bake only the current frame. The button changes to Baked when complete. Click the bin icon to delete the bake.

Save first and bake after final adjustments. Blender stores the bake beside the .blend file. Changes to wind settings, density, or the frame range require you to delete the existing bake and bake again.

Transition Effects

Animate a layer appearing or disappearing over a frame range. Twenty presets are available, each using the same basic Animation controls.

Preset

  • Default No Effect

Choose an effect under Preset and play the timeline. Examples include:

Popup: instances appear in a wave across the layer.
Radial: the layer grows outward from its centre.
Vortex: instances spin down into position.
Rain: instances fall into position from above.

The remaining presets are Aurora Front, Ripple, Geyser, Popcorn, Corkscrew, Spinup, Jelly Pop, Card Cascade, Orbit Assemble, Shutters, Seedling Timelapse, Sun Chase, Verdant, Pop Bounce, Meteor, and Bloom.

Animation settings

  • Start Frame 1
  • End Frame 60 to 90
  • Reverse off
  • Seed 0

Start Frame and End Frame define when the transition begins and when the layer is fully visible. Shorten the range to speed up the effect, or increase Start Frame to delay it.

Reverse plays the transition backward, starting with the complete layer and animating it out.

Seed changes the random order in which instances appear.

Each preset also includes an Effect Settings panel with its own controls, such as Edge Width for Radial or Spin and Drop Height for Vortex.

Collision

Flattens instances near an object, useful for grass reacting to a ball, foot, or wheel.

Collision Object and Distance

  • Default off
  • Min 0
  • Max 0.2

Enable Collision and select a Collision Object. Nearby instances bend down and return to their original state when the object moves away.

Max sets how far the effect reaches from the object. The default of 0.2 affects the immediate contact area. Increase it to flatten a wider area.

Min defines the distance within which instances are completely flat. Between Min and Max, the flattening is partial.

Group Dynamics

Select a group to access Group Dynamics. Its settings apply to every layer in the group, allowing a complete planting to share the same motion settings.
