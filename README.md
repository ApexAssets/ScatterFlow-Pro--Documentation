# ScatterFlow documentation

The documentation website for ScatterFlow Pro for Blender, the ScatterFlow plugin for Unreal Engine, and ScatterFlow Link for Godot.

It is a static site: plain HTML, CSS and JavaScript, with the demo videos in `videos/`. Open `index.html` to start.

## Publishing with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then the `main` branch and the `/ (root)` folder, and click **Save**.

The site is published at `https://<your-user-name>.github.io/<repository-name>/` a minute or two later.

`.nojekyll` tells GitHub Pages to publish the files as they are, without processing them.
