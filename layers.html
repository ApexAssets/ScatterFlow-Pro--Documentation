Emitter, layers and groups

Choose a surface, build your scatter in layers, and organize related layers into groups

Emitter Scatter layers Groups Group Scattering

Emitter

An emitter is the object a scatter setup belongs to, usually a terrain. Choose one to see its layers and the rest of the Scatter tab.

Emitter

Choose an object in the Emitter field, or pick one in the viewport with the eyedropper.

Each emitter has its own layer list. Use separate emitters to organize scattering across several terrains, such as a meadow and a hill.

Switching emitters only changes which list you are editing. Layers on other emitters stay active in the scene.

Scatter layers

A layer is one scatter setup: the objects it places, their density, and the masks and settings that control them. The System List shows the current emitter's layers, and the settings below it apply to the selected layer.

Add a layer

Click + beside the System List to add a layer, then choose its objects in the Instances section.

Double-click a layer's name to rename it. Clear names, such as Rocks, make the list easier to read.

New layers start with the density, scale, and rotation defaults from the add-on preferences.

Object Mode required. Switch Blender to Object Mode before adding a layer.

Show, hide and colour

The monitor icon shows or hides a layer in the viewport, and the camera icon does the same for renders. Hide heavy layers in the viewport but keep them on for rendering, so the scene stays easy to work with.

The colour swatch is only a label to help you tell layers apart. It does not change how they look in the scene.

Duplicate Layer

Choose Duplicate Layer from the arrow menu below the list buttons to copy the selected layer with all its settings.

The copy places instances in the same spots as the original. Change its Seed for a new arrangement, or choose different objects to reuse the layout with another asset.

Delete a layer

Select a layer, click −, and confirm. This removes the layer and its instances, but not the original objects.

Select and reorder

Click a row to edit that layer. Use the up and down arrows to reorder layers and keep related ones together.

Refresh List and Auto Refresh

Both are in the same arrow menu as Duplicate Layer.

Choose Refresh List from that menu to bring the System List up to date with the current scene. Use it if the list still shows layers from another scene after you switch.

Turn on Auto Refresh to do this automatically when the scene changes.

Groups

A group is a folder for several layers. It lets you hide, duplicate, or adjust them together.

Create a group and fill it

Click the folder button beside the System List to create an empty group, and double-click its name to rename it.

To add a layer, select it and click + on the group's row. Adding a layer to a group does not change its own settings.

The buttons on a group row

The triangle opens or closes the group.

The eye shows or hides every layer in the group, in both the viewport and renders.

The − button on a grouped layer's row takes that layer out of the group. The group stays, even when it is empty.

The duplicate icon copies the group with all its layers.

Deleting a group preserves its layers. Select the group and click the System List's − button. Only the folder is removed, and its layers move back to the top level of the list.

Group Scattering

Select a group to see the Group Scattering section instead of the layer's Scattering section. Its controls affect every layer in the group, while each layer keeps its own Density and Seed.

Density

  • Default 100%

Multiplies every layer's density by the same percentage. 100% leaves them unchanged, 50% halves them, and 200% doubles them.

Use it to thin out or fill in a whole biome while keeping the balance between trees, bushes, rocks, and other layers.

Seed Offset

  • Default 0

Shifts every layer's seed by the same amount. This gives the group a new arrangement, while each layer keeps its own seed and its own pattern.

Set it back to 0 to return to the original arrangement.

Type

  • Default Procedural
  • Group Spread 5.00

Switches every layer in the group between Procedural and Manual.

In Manual, the Start Placing button paints all the group's layers at once, so you can place a mix of trees, bushes, and rocks in one stroke.

Group Spread sets how far apart the layers place their instances around the brush. Lower values keep them close together; higher values spread them out.

See Manual Mode for the brush controls.

Other group sections

Selecting a group also shows group versions of other sections, such as Group Surface and Group Scale. These are covered on their own feature pages.
