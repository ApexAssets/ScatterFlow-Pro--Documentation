Emitter, layers and groups

Choose a surface, build your scatter in layers, and organize related layers into groups

Emitter Scatter layers Groups Group Scattering

Emitter

An emitter is the object a scatter setup belongs to, usually a terrain. Select an emitter to access the layer list and the rest of the Scatter tab.

Emitter

Choose an object in the Emitter field, or use the eyedropper to select one in the viewport. The System List and layer settings appear below it.

Each emitter has its own layer list. Use separate emitters to organize scattering across multiple terrains, such as a meadow and a hill.

Switching emitters changes the list you are editing. Layers assigned to other emitters remain active in the scene.

Scatter layers

A layer defines one scatter setup: the objects to place, their density, and the masks and other settings that control them. The System List displays the current emitter's layers. Settings below the list apply to the selected layer.

Add a layer

Click + beside the System List. A new layer named ScatterSystem is created and selected. Choose its source objects in the Instances section.

Double-click the layer name to rename it. Use descriptive names such as Rocks to identify its contents.

New layers use the default density, scale, and rotation settings from the add-on preferences.

Object Mode required. Switch Blender to Object Mode before adding a layer.

Show, hide and colour

The monitor icon controls a layer's viewport visibility. The camera icon controls its render visibility. Hide heavy layers in the viewport while leaving them enabled for rendering to keep the scene easier to work with.

The colour swatch on the left is an organizational label. Change it to distinguish related layers; it does not affect their appearance in the scene.

Duplicate Layer

Select a layer, open the arrow menu below the list buttons, and choose Duplicate Layer. The copy retains all settings and receives the original name with _Copy appended.

The copied layer initially places instances at the same positions as the original. Change its Seed to create a different arrangement, or choose different source objects to reuse the layout with another asset.

Delete a layer

Select a layer, click −, and confirm. This removes the layer and its scattered instances, but leaves the source objects unchanged.

Select and reorder

Click a row to edit that layer. The settings below the System List update to match your selection.

Use the up and down arrows to reorder layers and keep related entries together.

Refresh List and Auto Refresh

These options are available in the same arrow menu as Duplicate Layer.

Refresh List synchronizes the System List with the current scene. Use it if the list still shows layers from a previous scene after switching scenes.

Auto Refresh updates the list automatically when the scene changes.

Groups

A group organizes multiple layers in one folder. It also lets you hide, duplicate, or adjust those layers together.

Create a group and fill it

Click the folder button beside the System List to create an empty group. Double-click its name to rename it, for example Forest.

To add a layer, select it and click + on the group's row. The layer appears indented beneath the group.

Adding a layer to a group does not change its individual settings.

The buttons on a group row

The triangle expands or collapses the group's contents.

The eye shows or hides every layer in the group in both the viewport and renders.

The − on a grouped layer's row removes that layer from the group. The group remains even if it becomes empty.

The duplicate icon copies the group and all its layers.

Deleting a group preserves its layers. Select the group and click the System List's − button. Only the folder is removed; its layers return to the top level of the list.

Group Scattering

Select the group itself to display Group Scattering in place of the layer's Scattering section. These controls affect every layer in the group while preserving each layer's own Density and Seed values.

Density

  • Default 100%

Multiplies every layer's density by the same percentage. At 100%, densities are unchanged; 50% halves them, and 200% doubles them.

Use this to thin or fill out an entire biome while preserving the proportions of trees, bushes, rocks, and other layers. For example, 25% produces a sparse version of the group, while 250% makes it substantially denser.

Seed Offset

  • Default 0

Adds an offset to each layer's seed, changing the group's arrangement without replacing its individual seed values. Layers retain their different patterns.

Return the offset to 0 to restore the arrangement defined by the layers' own seeds.

Type

  • Default Procedural
  • Group Spread 5.00

Switches all layers in the group between Procedural and Manual scattering.

In Manual mode, Start Placing paints the group's layers together. Use it to place a mix of trees, bushes, and rocks with one stroke.

Group Spread controls how far apart the layers place their instances around the brush. Lower values create a tighter band; higher values spread the layers further apart.

See Manual Mode for the individual brush controls.

Other group sections

Selecting a group also displays group versions of other supported sections, including Group Surface and Group Scale. Their controls are covered on the corresponding feature pages.
