Megascans installer

Convert downloaded Megascans assets into a reusable Blender asset library

Install location The settings Install an asset Use it in a scene What an install makes

ScatterFlow extracts Megascans downloads, imports their models, builds materials from the included textures, and saves the results in the Megascans_SF asset library. Once installed, these assets are available through the Asset Browser in any Blender file.

Install location

Choose a library location before installing your first asset.

Megascans preferences

1. Open Edit > Preferences, select Add-ons, and expand ScatterFlow.

2. Expand Settings, then Megascans.

3. Set Folder to the location where you want to store Megascans assets. Allow room for both the extracted source files and the finished Blender assets.

4. Click Register / Refresh Asset Library. ScatterFlow creates the folder if needed and registers it as Megascans_SF in Blender.

See The settings, one by one for details about each option.

The settings, one by one

The Megascans panel contains two settings and one library registration button.

Folder

Sets the location for all installed Megascans content. Until you choose a folder, the panel displays Choose a folder before installing Megascans assets. and disables the button below it.

The folder contains three items:

Assets: one .blend file per asset, organized by type, such as 3D Assets, 3D Plants, and Surfaces. These files appear in the Asset Browser.
SourceFiles: the extracted downloads, including their models and full-resolution textures. Asset materials reference textures here, so do not delete this folder.
blender_assets.cats.txt: the catalog definitions used to organize the Asset Browser.

A single extracted download can occupy several hundred megabytes. To relocate the library, move the entire folder, update Folder, and click Register / Refresh Asset Library.

Install LOD Versions

  • Default Off

Some Megascans downloads include multiple levels of detail (LODs). LOD0 is the most detailed model; LOD1, LOD2, and subsequent versions use progressively fewer polygons.

Off: installs only the most detailed version of each model. Use this when you need the full-detail asset for Blender rendering. Omitting the additional LODs keeps the installed files smaller than installing all versions.

On: installs every available LOD into the same asset. Its description lists the included versions, for example Included LODs: LOD0, LOD1, LOD2. Use this when you also need lighter models for distant scattering or game engine use.

This option applies during installation. Changing it does not alter existing assets; reinstall a download to change which LODs it includes.

Register / Refresh Asset Library

Registers the selected folder with Blender and refreshes its library setup:

1. Creates the folder if it does not exist.

2. Adds Megascans_SF under Edit > Preferences > Asset Libraries with the import method set to Append. Assets added to a scene become editable copies.

3. Creates the Megascans catalogs: 3D Assets, 3D Plants, Surfaces, Decals, Atlases, Imperfections, and Brushes.

4. Refreshes open Asset Browsers and saves the preferences so the library remains registered after restarting Blender.

When complete, the status bar displays Megascans_SF ready and the library location. Installing an asset also performs these steps. Use the button during initial setup, after changing Folder, or when the library is missing from the Asset Browser.

Install an asset

Install Megascans

1. Open an Asset Browser. You can change an existing editor, such as the Timeline, to an Asset Browser.

2. Click Install Megascans on the right side of its header.

3. Select a downloaded Megascans .zip and confirm. You can select multiple zip files, or browse into an already extracted Megascans folder.

4. Choose Megascans_SF from the library menu. The installed asset appears with a preview in its matching Megascans catalog.

Asset not visible? Click the refresh arrows beside the library menu.

Use it in a scene

Drag and drop

Drag an asset from the Asset Browser into the 3D viewport. It becomes an ordinary object that you can move, edit, or scatter.

Its material is already configured with the available colour, roughness, normal, and displacement textures. Inspect the connections in the Shader Editor, or use Material Preview or Rendered shading to view the result.

Assets are appended rather than linked, so editing an imported object does not change the library copy.

To scatter an object, select it in a layer's Instances section.

What an install makes

Models, plants and surfaces

The installer reads the download's metadata to identify its asset type and select the matching catalog.

3D assets and 3D plants become model assets. A download containing several variations becomes one asset containing all of them, with a description such as Contains 3 variations. Dragging it into a scene imports every variation, ready to use together in a scatter layer.

Surfaces, decals, imperfections, atlases, and brushes contain textures rather than models and become material assets. Drag one onto an object to apply the material.

Supported model formats are FBX, OBJ, glTF, USD, Alembic, PLY, and STL. Supported texture formats are JPG, PNG, TIFF, EXR, TGA, BMP, WebP, and HDR.

The material

Materials are assembled from textures identified by filename. Supported inputs include colour, ambient occlusion, roughness, gloss, metalness, specular, normal, bump, displacement, opacity, and translucency. Ambient occlusion is multiplied into the colour, and gloss maps are converted to roughness. The highest-resolution version of each texture is used.

Opacity maps configure cutout materials for assets such as leaves and grass. Displacement maps set the material to Displacement and Bump: in Cycles, displacement moves the surface when the mesh has sufficient geometry; otherwise, it contributes bump detail.

Installing the same asset again

Reinstalling an asset replaces its .blend file and its extracted copy in SourceFiles. Use this to change the included LODs or repair an asset.

Objects already imported into Blender scenes are separate copies and are not replaced by the reinstall.

When an install fails

“Choose an Asset Library folder first.” Set Folder in the Megascans preferences. See Install location.

“Select a Megascans ZIP, or browse into a Megascans folder.” Select the zip files themselves, or open an extracted Megascans folder and click Install Megascans without selecting an individual file.

“No supported mesh or Megascans texture maps were found in that source.” The selected source contains no recognized model or texture files. Check that it is a supported Megascans download.

“Installed 2 of 3 source(s). 1 failed; see System Console.” One or more downloads failed during a batch installation. Open Window > Toggle System Console to see the reason for each failure.
