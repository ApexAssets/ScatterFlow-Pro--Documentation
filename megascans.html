Megascans installer

Convert downloaded Megascans assets into a reusable Blender asset library

Install location The settings Install an asset Use it in a scene What an install makes

ScatterFlow turns your Megascans downloads into ready-to-use Blender assets, with their materials already set up. They are saved in the Megascans_SF asset library, so you can use them from the Asset Browser in any Blender file.

Install location

Choose a library location before installing your first asset.

Megascans preferences

The Megascans settings are in ScatterFlow's add-on preferences, in the Megascans section of the Settings panel. Set the Folder field to where you want to keep your Megascans assets, then click the Register / Refresh Asset Library button.

Pick a location with room for both the extracted downloads and the finished Blender assets.

See The settings, one by one for details on each option.

The settings, one by one

The Megascans panel has two settings and a button that registers the library.

Folder

Where all your installed Megascans content is kept. You need to choose a folder before you can install anything.

Inside it, the Assets folder holds one .blend file per asset, sorted by type. These are what the Asset Browser shows. SourceFiles holds the extracted downloads with their full-resolution textures. The materials use these textures, so do not delete this folder. blender_assets.cats.txt stores the Asset Browser catalogs.

One extracted download can take several hundred megabytes. To move the library, move the whole folder, update the Folder field, and click the Register / Refresh Asset Library button.

Install LOD Versions

  • Default Off

Some Megascans downloads include several levels of detail (LODs). LOD0 is the most detailed model, and each higher number has fewer polygons.

Off: installs only the most detailed model, which keeps the files smaller. Use it when you render in Blender.

On: installs every LOD into the same asset, and the asset's description lists which ones it has. Use it when you also need lighter models for distant scattering or game engines.

The setting only applies when you install. It does not change existing assets, so install a download again to change its LODs.

Register / Refresh Asset Library

Registers your folder in Blender as the Megascans_SF asset library. It creates the folder and the Megascans catalogs if they are missing, and saves your preferences so the library is still there after you restart Blender.

The library uses the Append import method, so assets you add to a scene are editable copies.

Installing an asset does all of this too. Use the button when you first set up, after changing the Folder field, or if the library is missing from the Asset Browser.

Install an asset

Install Megascans

Click the Install Megascans button in the header of an Asset Browser and choose one or more downloaded Megascans .zip files. You can also browse into a Megascans folder you have already extracted.

Any editor, such as the Timeline, can be switched to an Asset Browser.

Installed assets are in the Megascans_SF library, sorted into its Megascans catalogs.

Asset not visible? Click the refresh arrows beside the library menu.

Use it in a scene

Drag and drop

Drag an asset from the Asset Browser into the viewport. It becomes an ordinary object that you can move, edit, or scatter.

Its material is already set up with the textures that came with it, such as colour, roughness, normal, and displacement.

Assets are appended, not linked, so editing one in your scene does not change the library copy.

To scatter it, choose it in a layer's Instances section.

What an install makes

Models, plants and surfaces

The installer detects each download's type and puts it in the matching catalog.

3D assets and 3D plants become model assets. A download with several variations becomes one asset that holds them all. Dragging it into a scene brings in every variation, ready to use together in a scatter layer.

Surfaces, decals, imperfections, atlases, and brushes have only textures, so they become material assets. Drag one onto an object to apply it.

Supported model formats are FBX, OBJ, glTF, USD, Alembic, PLY, and STL. Supported texture formats are JPG, PNG, TIFF, EXR, TGA, BMP, WebP, and HDR.

The material

The material is built from the download's textures, recognised by filename. All the common maps are supported, including colour, roughness or gloss, normal, displacement, opacity, and translucency. The highest-resolution version of each texture is used.

Opacity maps give cutout materials for leaves and grass. With a displacement map, the material uses Displacement and Bump. In Cycles, the surface is displaced when the mesh has enough geometry; otherwise it adds bump detail.

Installing the same asset again

Installing an asset again replaces its .blend file and its files in SourceFiles. Use this to change its LODs or to repair it.

Objects already in your scenes are separate copies, so they are not updated.

When an install fails

“Choose an Asset Library folder first.” Set the Folder field in the Megascans preferences. See Install location.

“Select a Megascans ZIP, or browse into a Megascans folder.” Select the .zip files themselves, or open an extracted Megascans folder and click the Install Megascans button without selecting a file.

“No supported mesh or Megascans texture maps were found in that source.” No model or texture files were recognised. Check that it is a supported Megascans download.

“Installed 2 of 3 source(s). 1 failed; see System Console.” Some downloads in a batch failed. Choose Window > Toggle System Console from Blender's top menu to see why.
