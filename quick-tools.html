Quick Tools

Vary manually placed objects and position them on the ground

Randomize Transform Snap to Ground

Quick Tools are the two buttons at the top of the Scatter tab. They work on selected mesh objects, not scatter layers, and stay greyed out until you select a mesh.

After using a tool, change its options in Blender's Adjust Last Operation panel at the lower left of the viewport, or press F9. The result updates as you change them.

Randomize Transform

Adds random variation to the size, heading, and tilt of selected objects, so repeated props look less alike.

Randomize Transform

Click the button again for a different result. Each click starts from the objects' original scale and rotation, not the last result, so repeated clicks do not keep shrinking or tilting them.

Original transforms are stored for the current session. If you scale or rotate an object yourself after randomizing, that becomes its new starting point.

Options

  • Scale Min 0.5
  • Scale Max 1.0
  • Max Tilt 15°
  • Random Yaw on

Scale Min and Scale Max set the size range. By default, objects end up between half and full size. Set Scale Max above 1 to allow larger objects.

Max Tilt sets how far objects can lean from upright, up to 90°. Use 0 to keep them upright.

Random Yaw turns each object randomly around its vertical axis. Turn it off to keep the original heading.

Seed controls the random result. Each click picks a new seed; enter one yourself to repeat a result.

Snap to Ground

Moves objects straight up or down until their lowest point rests on the surface below. Objects above the ground move down, and objects sunk into it can move up.

Snap to Ground

The tool only changes height. It does not tilt objects to match the slope.

Selected objects ignore each other, so they land on the terrain instead of stacking on top of one another. Objects with no surface below them are left where they are.

Options

  • Search Distance 250 m
  • Ground Offset 0 m
  • Use Footprint on

Ground Offset leaves a gap between objects and the surface. At 0 they rest on it. Negative values sink the base slightly, which suits rocks and tree trunks.

Use Footprint checks the ground under the object's centre and four corners and uses the highest point, so objects sink less on slopes. Turn it off to check only the centre.

Search Distance sets how far below each object the tool looks for a surface.

Recorded in ScatterFlow 1.0.9 on the ScatterFlow build of Blender 5.2.2, using the assets bundled with the add-on.
