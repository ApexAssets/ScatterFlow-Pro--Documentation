ScatterFlow documentation / Scatter

Quick Tools

Vary manually placed objects and position them on the ground

Randomize Transform Snap to Ground

Quick Tools are the two buttons at the top of the Scatter tab. They operate on selected mesh objects, not scatter layers, and remain disabled until a mesh is selected.

After using a tool, adjust its options in Blender's Adjust Last Operation panel at the lower left of the viewport, or press F9. Changing an option immediately updates the result.

Randomize Transform

Adds variation to the scale, heading, and tilt of selected objects. Use it to make repeated props look less uniform.

Randomize Transform

Select the objects and click the button. Click again to generate another result.

Each operation starts from the stored original scale and rotation rather than the previous randomized result. Repeated clicks therefore do not continually shrink or tilt the objects.

Original transforms are stored for the current session. Manually scaling or rotating an object after randomizing establishes a new starting transform.

Options

  • Scale Min 0.5
  • Scale Max 1.0
  • Max Tilt 15°
  • Random Yaw on

Scale Min and Scale Max define the random scale range. The defaults produce objects between half and full size. Set Scale Max above 1 to allow larger variations.

Max Tilt sets the maximum lean away from vertical, up to 90°. Use 0 to keep objects upright.

Random Yaw rotates each object randomly around its vertical axis. Disable it to preserve the original heading.

Seed controls the random result. Each button click chooses a new seed; enter a specific value to reproduce a result.

Snap to Ground

Moves objects vertically until their lowest point rests on the surface beneath them. Objects above the ground move down; objects embedded in it can move up.

Snap to Ground

Select the objects and click the button. Each object is positioned on the surface beneath it.

The tool changes vertical position only. It does not rotate objects to match the slope.

Selected objects are excluded from one another's ground checks, so they land on the terrain rather than stacking on each other. Objects with no detected surface below them remain unchanged.

Options

  • Search Distance 250 m
  • Ground Offset 0 m
  • Use Footprint on

Ground Offset adds vertical clearance. At 0, objects rest on the surface; a value of 2 m leaves a 2 m gap. Negative values embed the base slightly, useful for rocks and tree trunks.

Use Footprint checks the ground below the object's centre and four corners, then uses the highest detected point to reduce sinking on slopes. Disable it to check only the centre.

Search Distance sets how far below each object the tool searches for a surface.

Recorded in ScatterFlow 1.0.9 on the ScatterFlow build of Blender 5.2.2, using the assets bundled with the add-on.
