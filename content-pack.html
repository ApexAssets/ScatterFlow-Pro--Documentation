Content pack and the Asset Browser

Browse ScatterFlow plants, rocks, and props, then place them directly or use them in scatter layers

Adding the library Browsing the pack Dropping assets in Scattering an asset

The ScatterFlow content pack includes plants, rocks, props, and effects. Its assets are used by the bundled biomes, but you can also add them individually through Blender's Asset Browser.

After installing the content, register its folder as an asset library so Blender can display it.

Adding the library

Register the library once in Blender's Asset Libraries preferences. This is a separate step from installing the files with ScatterFlow's Content Installer.

Set the asset library path

1. Open Edit > Preferences and select Asset Libraries.

2. Click + beside the library list and select the ScatterFlow_Pro_ContentPack folder. Select the folder itself, not a file inside it.

3. Select the new library entry and check that its Path ends with ScatterFlow_Pro_ContentPack.

4. Set Import Method to Append. Assets added to a scene will become editable copies in that file.

5. Close Preferences. The library is now available in the menu at the upper left of any Asset Browser.

Update the path after moving the library. If the assets disappear after you move the folder, return to these preferences and set Path to its new location.

Browsing the pack

Library, catalogs and search

Open an Asset Browser. You can change an existing editor, such as the Timeline, to an Asset Browser and resize it to show more assets.

Choose ScatterFlow_Pro_ContentPack from the library menu. The catalogs organize the assets into the following groups:

Foliage: Bushes, Cactus, Grass, Ground Debris, Moss, Mushrooms, Plants, Rocks, Sticks, and Trees.
Ivy: leaves, flowers, and presets for the Ivy tools.
Trash & Debris: barrels, boxes, construction debris, bins, food and drink, glass, set pieces, and loose trash.
Water, Weather, and Atmosphere: water presets, rain, snow, wind, and effects such as dust, embers, and falling leaves.

Select a catalog to filter the assets, or expand its arrow to browse subcategories. Use Search to find assets by name, such as “fern.”

Initial loading may take longer. The library is large, and asset previews may take a moment to appear the first time you open it.

Dropping assets in

Drag and drop

Drag an asset into the 3D viewport and release it over the target surface. The asset snaps to the surface beneath the cursor.

Most assets contain several variations rather than a single object. For example, Ferns includes four ferns, while Desert Rocks2 includes sixteen rocks. The variations arrive in a row, grouped in a collection named after the asset. Reposition them or remove variations you do not need.

Materials are included. Switch to Material Preview or Rendered shading to see the textures.

For manually placed props, use Randomize Transform to vary their appearance and Snap to Ground to position them on the terrain.

Scattering an asset

From an asset to a scatter layer

An imported asset's collection of variations can be used directly as the source for a scatter layer.

1. Drag the asset into the scene.

2. Choose an Emitter in the ScatterFlow panel and click + to add a layer.

3. Under Instances, set Type to Multiple Instances and select the asset's collection, such as Ferns.

4. Increase Density / m² to populate the surface. The layer uses the variations in the collection.

You can now adjust the layer with the Scatter tab's controls, including Scale, Rotation, masks, and Wind. Supported content pack materials also respond to the Materials section's season, snow, and dryness settings.

After setup, you can hide the original objects or move them out of view. Keep them in the file: the scatter layer uses them as its source objects.

Recorded in ScatterFlow 1.0.9 on the ScatterFlow build of Blender 5.2.2, using the ScatterFlow content pack.
