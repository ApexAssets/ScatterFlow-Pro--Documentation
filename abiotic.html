Abiotic masks

Place instances according to terrain slope, elevation, and facing direction

Slope Mask Elevation Mask Angle Mask

The Abiotic section contains three masks that control placement using the shape of the terrain. Select a layer in the System List, enable a mask, and expand it to access its settings. Each layer has its own masks, and all three can be combined.

These masks hide instances by reducing their scale to zero. Smooth transitions therefore change instance size at the boundary rather than gradually reducing instance density.

The Abiotic section is located between Culling and Proximity in the Scatter tab.

Slope Mask

Restricts a layer to flatter ground, or to steeper ground when inverted. Use it to keep trees on terraces while leaving cliff faces clear.

Slope

  • Default 0.85
  • Range 0 to 1

Sets the minimum flatness required to keep an instance. A value of 1 represents level ground; 0 represents a vertical wall. The layer appears on surfaces flatter than the threshold.

Increase Slope to restrict placement to flatter terrain. Decrease it to allow steeper slopes.

As a guide, 0.85 allows slopes of approximately 32°, 0.7 allows 45°, and 0.5 allows 60°.

Smooth Transition

  • Default off
  • Transition 0.5

Blends instance size across the slope boundary. Instances have zero scale at the cutoff and reach full size where the surface is flatter by the Transition amount.

A small Transition creates a narrow band of smaller instances. A larger value extends that band further onto flat ground.

Keep Slope + Transition at or below 1. Surface flatness cannot exceed 1. With a higher total, instances cannot reach full size. At the defaults of 0.85 and 0.5, even level ground produces instances at 30% scale. A Transition of 0.05–0.15 is a useful starting range for most scenes.

Invert

  • Default off

Reverses the mask, keeping the layer on steep surfaces and excluding it from flat ground. With Invert enabled, decreasing Slope restricts placement to progressively steeper surfaces.

Use an inverted mask for rocks or scree on a cliff, alongside a plant layer using the same Slope value without inversion.

Elevation Mask

Restricts placement by height. Use it to create boundaries such as a mountain tree line.

Height

  • Default 5 m

Sets the upper height limit when Smooth Transition is disabled. Instances above the cutoff are excluded.

Height is measured along the scene's Z axis in scene units. Account for the terrain's position when choosing a value, especially if it sits far above or below zero.

Layer disappears after enabling the mask? The default cutoff is 5 m. If the whole emitter is above that height, increase Height until the layer becomes visible.

Smooth Transition

  • Default off
  • Transition 5

Extends a scale fade above the cutoff. Instances remain full size up to Height, then shrink to zero over the next Transition metres.

For example, Height at 7 m and Transition at 5 fades instances between 7 m and 12 m. Use a shorter transition for a distinct tree line or a longer one for a more gradual boundary.

Invert

  • Default off

Keeps instances above the cutoff instead of below it. Height becomes the layer's lower boundary.

Use it for high-altitude plants or rocks near a snow line. Two layers with the same Height and opposite Invert settings can divide a terrain into upper and lower regions.

Randomize

  • Default off
  • Amount 55
  • Scale 0.2

Varies the height cutoff with noise so the boundary does not follow a uniform contour.

Amount controls how far the cutoff can shift. At 0, it remains unchanged. The default of 55 suits large terrains; reduce it for smaller terrain where the variation would otherwise be too strong.

Scale controls the frequency of the pattern. Lower values produce broad variations in the boundary; higher values produce smaller, more frequent changes.

Angle Mask

Restricts placement according to the direction a slope faces. Use it for effects such as moss on shaded hillsides or plants on slopes facing the sun.

Angle

  • Default 0°

Sets the compass direction the slope must face. Adjusting Angle through 360° changes the affected side of every hill.

Without Smooth Transition, instance size depends on how directly the slope faces that direction. Steep surfaces facing it directly produce the largest instances, with scale tapering toward the sides. Level ground has no facing direction and remains empty at the default Offset.

Offset

  • Default 0

Adjusts the width of the affected region.

Positive values restrict placement to steeper surfaces facing the chosen angle. Negative values extend it around the hillside and allow instances onto level ground.

Smooth Transition

  • Default off
  • Transition 0.5

Controls the blend from zero to full instance scale across the mask boundary.

Use a small Transition for full-size instances with a distinct edge. Larger values create a broader, softer region of reduced-scale instances.

Enabling Smooth Transition slightly narrows the mask. Decrease Offset to restore the previous coverage.
