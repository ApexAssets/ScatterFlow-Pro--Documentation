ScatterFlow documentation / Godot plugin

Godot: Wind

Set project-wide wind and adjust how individual layers respond

Beta ScatterFlow Link for Godot is in early development. Features, settings, and interface elements may change between releases.

Wind

ScatterFlow wind combines Global Wind settings for the project with individual layer controls. Use the global settings for the overall motion, then adjust each layer's response.

Global Wind

Deselect the layer and expand Global Wind.

Enabled: toggles wind throughout the project.

Strength: controls how far plants bend.
Speed: controls how quickly they sway.

Wind settings are stored in the project and also apply in the exported game.

Layer Wind

Select a layer and expand Wind. Adjust its response so different assets, such as stiff bushes and flexible grass, move differently under the same global wind.

Strength: a multiplier on global strength. At 0, the layer remains still; 1 uses the global value; higher values increase bending.
Speed: movement speed relative to global wind speed.
Gust: varies the movement from a steady sway at 0 to gusting motion at 1.
Direction: the direction the wind blows toward, in degrees (0° is +X).
Leaf Flutter: adds smaller, faster leaf movement over the main sway.

Recorded with ScatterFlow Link 1.8.0 in Godot 4.7.2, linked to ScatterFlow 1.0.9 in Blender 5.2.2.
