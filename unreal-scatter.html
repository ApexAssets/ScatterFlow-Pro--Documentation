Unreal: Scatter Layers

Adjust imported layers or regenerate their placement directly in Unreal

Beta The ScatterFlow plugin for Unreal Engine is in early development. Features, settings, and interface elements may change between releases.
Editing layers Procedural settings Masking

Editing layers

Settings you change in Unreal show a round-arrow button, Reset to the value from Blender. Click it to return that setting to its imported value.

Mode: Blender Exact or Procedural

The two mode buttons choose how the layer is placed.

Blender Exact keeps the instance positions from Blender. Use it when placement must match the original, especially for layers you arranged by hand.

Procedural rebuilds the scatter in Unreal with its PCG system. It adds density, spacing, and mask controls, and lets the layer follow changes to the ground.

The panel only shows the settings for the current mode. Switch back to Blender Exact at any time to return to the imported placement.

Exact Adjustments

These change the imported instances without creating a new layout.

Z Offset (cm) moves every instance up or down. Use it to fix floating bases or exposed roots.

Keep Ratio (thinning) sets how many instances are kept, chosen at random. At 1 every instance stays; at 0.5 half of them do. Use it to thin a layer without changing positions.

Scale

Scale Multiplier scales all instances relative to their Blender size. At 1 they are unchanged.

Random Scale Min and Random Scale Max add a random size factor between the two values. Set both to 1 for no extra variation.

Rotation

Rotation X / Y / Z (deg) rotates all instances. Use X or Y to lean the layer, and Z to turn it.

Random Spin (+/- deg) adds a random turn around each instance's up axis, up to the angle you set in either direction.

Meshes

The Meshes section lists the layer's source meshes and how many instances use each one.

To replace a mesh, click its name and pick a new asset. You can also select a mesh in the Content Browser or Content Drawer, then click the arrow beside the name. The folder button finds the current mesh in the Content Browser without replacing it.

Replacing a mesh updates every instance that uses it.

Re-exporting replaces the mesh list. The next export from Blender brings back Blender's list. Make lasting mesh changes in Blender.

Adding and removing meshes

In Procedural mode you can add meshes to the layer. Pick one from the Add Mesh asset picker to add it. The Add Selected from Content Browser button adds every static mesh selected in the Content Browser or Content Drawer.

Weight sets how often a mesh is used compared with the others. A mesh with a weight of 3 is used three times as often as one with a weight of 1.

Meshes added in Unreal can be removed with their x button. Meshes from Blender cannot be removed here.

Editing several layers at once

Ctrl+click instances, or layer actors in the Outliner, to select several layers. Your changes then apply to all of them.

This is useful for adjusting related layers together, such as trees and bushes.

Advanced: Actions

The Regenerate button rebuilds the placement on the current ground. Use it after sculpting a Landscape or changing a surface's collision.

The Select in Level button selects the layer actors in the level and Outliner.

The Open PCG Graph button opens the graph Unreal uses to build the layer. Use it when you want to inspect or work with the PCG setup directly.

Procedural settings

These controls are available in Procedural mode. The layer updates as soon as you change a setting.

Surface: what the layer grows on

The Terrain + Landscape button is the default. The layer only grows on its imported terrain and Unreal Landscapes, so objects standing on the terrain stay clear.

Click Any Geometry to let the layer grow on any geometry below the scatter points. Use it when assets should also cover surfaces such as roofs or boulders.

Use Selected Actor as Surface

Use this to let the layer grow on one specific object, without allowing all geometry.

Select the object, Ctrl+click an instance from the layer so both are selected, then click Use Selected Actor as Surface in the Surface section. Only that object receives instances; other objects stay excluded.

Z Offset

Z Offset (cm) raises or lowers all instances. Use small positive values for bases that sit too low, or negative values to sink them slightly. Check the result from ground level.

Density and Density Multiplier

Density / m² is the number of instances per square metre. It starts at the value from Blender.

Density Multiplier scales the density without changing that base value. Use it to try denser or sparser versions of the layer.

A top-down view makes coverage and spacing easier to judge.

Seed

Changes the random layout while keeping the other settings and the instance count. Try a few seeds to find an arrangement you like.

Min Distance

Min Distance (cm) sets the smallest gap between instances. Instances that are too close together are removed.

Raise it to reduce clumping and spread instances more evenly. Higher values can lower the final count, even when Density stays the same.

Uniform and Non-Uniform Scale

Uniform Scale changes the size of every instance.

Non-Uniform scales X, Y, and Z separately. Use Z to change height, and X or Y to change width.

Random Scale

Turn on Random Scale to give each instance a size between Min Scale and Max Scale, multiplied by Uniform Scale. A wider range gives more variety in size.

Align to Surface and tilt

Turn on Align to Surface to make instances stand at right angles to the ground below them. Use it for rocks, grass, and ground cover. Leave it off for trees that should stay upright on slopes.

The X and Y values in Range X / Y / Z (deg) add random tilt, up to the angle you set. Around 5–15° breaks up instances that look too evenly upright.

Random Rotation

Turn on Random Rotation to vary which way instances face, which hides repetition. Turn it off to keep them facing the same way.

The Z value in Range X / Y / Z limits that variation. At 360° instances can face any direction, and at 0 they all face the same way.

Masking

Masks limit procedural placement to parts of the surface, and are available in Procedural mode. Each mask has an Enabled checkbox, and the Invert checkbox flips the area it affects.

Slope

Use this mask to keep vegetation on flatter ground, or to keep assets on steep surfaces only.

Max Slope is the steepest angle allowed, in degrees. Lower it to clear steep banks while keeping flatter ground. Falloff (deg) softens the edge of the mask.

Turn on Invert to keep instances on steep ground instead of flat areas.

Elevation

Use this mask for height limits, such as a tree line.

Height (cm) is the highest point the layer reaches, entered in centimetres. Falloff (cm) is the height range over which the layer fades out at that limit.

Turn on Invert to keep instances above the limit instead of below it.

Noise

Breaks the layer into irregular patches instead of even coverage.

Scale (lower = bigger patches) sets the size of the patches. Threshold Min and Threshold Max set how much is covered and how soft the patch edges are. A wider gap between them gives softer edges.

Detail adds finer variation to the patch edges. Seed rearranges the pattern without changing its other settings. Turn on Invert to swap the patches and the gaps.

Geometry Proximity

Controls placement around chosen objects, such as keeping plants away from a house.

Select the object, Ctrl+click an instance to add the layer to the selection, then click Add Selected under Geometry Proximity. This also turns the mask on.

Distance (cm) sets how far around the object the mask reaches, and Transition (cm) softens its edge. Under Behaviour, click Repel to clear instances near the object, or Attract to keep them only near it.

Click an object's x to remove it. The Clear button removes all objects added in Unreal. Objects that came from Blender stay, and are counted separately above the list.

Curve Proximity

Uses a spline to shape a path, road, riverbank, or other long region.

Select the layer and click Draw New Spline. A short spline appears where the viewport is looking. Move its points to shape it, and Alt+drag an endpoint to add more points.

Then select the layer again to set Distance (cm), which is how far the mask reaches on each side of the spline. With Repel, 0 clears nothing. Transition (cm) softens the outer edges. Under Behaviour, click Attract to keep instances along the spline, or Repel to clear them away from it.

To use an existing actor with a Spline component, select it together with the layer and click Add Selected under Curve Proximity. When you edit the spline, the scatter updates as you release a point.
