Unreal: Scatter Layers

Adjust imported layers or regenerate their placement directly in Unreal

Beta The ScatterFlow plugin for Unreal Engine is in early development. Features, settings, and interface elements may change between releases.
Editing layers Procedural settings Masking

Editing layers

Modified settings display a round-arrow button labeled Reset to the value from Blender. Click it to restore that setting's imported value.

Mode: Blender Exact or Procedural

Use the two mode buttons to choose how the layer is placed.

Blender Exact preserves the instance positions exported from Blender. Use it when placement must match the original, especially for manually arranged layers.

Procedural regenerates the scatter in Unreal using its PCG system. It provides density, spacing, and mask controls, and lets the layer respond to changes in the ground.

The panel displays the settings available for the selected mode. You can switch back to Blender Exact to return to the imported placement.

Exact Adjustments

These controls modify the imported instances without generating a new layout.

Z Offset (cm): moves every instance vertically. Positive values raise it; negative values embed it in the ground. Use it to correct floating bases or exposed roots.

Keep Ratio (thinning): sets the proportion retained. A value of 1 keeps every instance, while 0.5 keeps half at random. Use it to reduce density without regenerating positions.

Scale

Expand Scale to access the size controls.

Scale Multiplier: scales all instances relative to their Blender sizes. A value of 1 leaves them unchanged.

Random Scale Min and Random Scale Max: add a random scale factor between the two values. Set both to 1 for no additional variation.

Rotation

Rotation X / Y / Z (deg): rotates all instances by the specified angles. Use X or Y to lean a layer and Z to change its heading.

Random Spin (+/- deg): adds random rotation around each instance's up axis, within the specified angle in either direction.

Meshes

The Meshes section lists each source mesh, such as Mesh 1 and Mesh 2, with its instance count.

Use the controls beside a mesh to replace it or locate its asset:

1. Click the mesh name to open the asset picker. Search for and select a replacement.
2. Select a mesh in the Content Browser or Content Drawer, then click the arrow beside the mesh name to assign it.
3. Click the folder button to locate the current mesh in the Content Browser. This does not replace it.

Replacing a source mesh updates every instance that uses that slot.

Re-exporting replaces the mesh list. The next Blender export restores Blender's list. Make lasting source-mesh changes in Blender.

Adding and removing meshes

In Procedural mode, you can add meshes to the layer:

Add Mesh: opens the asset picker and adds the chosen mesh.
Add Selected from Content Browser: adds all selected static meshes from the Content Browser or Content Drawer.

Weight: controls how often a mesh is selected relative to others. For example, set a bush's weight to 3 and a rock's to 1 to use the bush three times as often.

Meshes added in Unreal have an x button for removal. Meshes imported from Blender cannot be removed here.

Editing several layers at once

Ctrl+click instances or layer actors in the Outliner to select multiple layers. The panel reports the number selected, such as Editing 2 layers, and changes apply to all of them.

Use this to adjust the scale of trees and bushes together, then reset the modified settings when comparing results.

Advanced: Actions

Regenerate: recalculates placement using the current ground. Use it after sculpting a Landscape or changing a surface's collision.

Select in Level: selects the layer actors in the level and Outliner.

Open PCG Graph: opens the graph Unreal uses to generate the layer. This is intended for users who need to inspect or work with the underlying PCG setup.

Procedural settings

These controls appear in Procedural mode. Changing a setting regenerates the layer and updates the viewport.

Surface: what the layer grows on

Terrain + Landscape is the default. It restricts placement to the layer's imported terrain and Unreal Landscapes, leaving objects on top of the terrain clear.

Any Geometry allows placement on geometry beneath the scatter points.

Use Any Geometry when assets should also cover surfaces such as roofs or boulders. Return to Terrain + Landscape to keep those surfaces excluded.

Use Selected Actor as Surface

To add one specific object as a surface without allowing all geometry:

1. Select the target object, such as a boulder.
2. Ctrl+click an instance from the layer so both the object and layer are selected.
3. Expand Surface and click Use Selected Actor as Surface.

The selected object receives instances while unrelated objects remain excluded.

Z Offset

Z Offset (cm) raises or lowers all instances. Use small positive values for bases that sit too low, or negative values to embed them slightly. Inspect the result from ground level to judge contact with the surface.

Density and Density Multiplier

Use a top-down view to evaluate changes in coverage and spacing.

Density / m²: the number of instances per square metre, initially taken from Blender. Increasing it from 0.03 to 0.15 multiplies the base density by five.

Density Multiplier: scales the density without replacing the base value. Use it to compare denser or sparser versions of the layer.

Seed

Changes the random layout while retaining the other settings and instance count. Try different seeds to adjust the arrangement without rebuilding the setup.

Min Distance

Min Distance (cm) sets the minimum spacing between instances. Instances that are too close to one another are removed.

Increase it to reduce clustering and produce more even spacing. Higher values can reduce the final count even when Density remains unchanged.

Uniform and Non-Uniform Scale

Uniform Scale: adjusts the size of every instance.

Non-Uniform: scales X, Y, and Z independently. Use Z to change height and X or Y to change width.

Random Scale

Enable Random Scale to assign each instance a factor between Min Scale and Max Scale, multiplied by Uniform Scale. Wider ranges create stronger size variation; 0.4–2.0, for example, mixes substantially smaller and larger trees.

Align to Surface and tilt

Use a hillside, such as a 30° slope, to inspect alignment clearly.

Align to Surface: makes instances stand perpendicular to the ground beneath them. This suits rocks, grass, and ground cover. Leave it disabled for trees that should remain vertical on slopes.

Range X / Y / Z (deg): the X and Y controls add random tilt up to the specified angles. Values around 5–15° can break up uniformly upright placement.

Random Rotation

Enable Random Rotation to vary instance orientation and reduce visible repetition. Disable it to preserve matching orientations.

The Z value in Range X / Y / Z limits the heading variation. At 360°, instances can face any direction. Lower values restrict the range; 0 removes the variation.

Masking

Masks restrict procedural placement to selected parts of the surface. Each has an Enabled control, and Invert reverses its affected region. Masks are available in Procedural mode.

Slope

Use this mask to keep vegetation on flatter ground or restrict assets to steep surfaces.

Max Slope: the steepest allowed surface angle, in degrees. Lowering it from 76 to 15 clears steep banks while retaining flatter terraces.

Falloff (deg): softens the transition at the slope boundary.

Invert: reverses the mask to keep instances on steep ground instead of flat areas.

Elevation

Use this mask for height-based boundaries such as a tree line.

Height (cm): the upper placement limit. On a 10 m hill, changing the limit between 1.5 m and 7 m substantially changes the covered area; enter the corresponding values in centimetres.

Falloff (cm): the height range over which the layer fades at the boundary.

Invert: keeps instances above the height limit instead of below it.

Noise

Breaks the layer into irregular patches rather than uniform coverage.

Scale (lower = bigger patches): controls pattern size. Decrease it for broader patches.
Threshold Min and Threshold Max: control coverage and the transition between patches and gaps. A wider interval creates softer boundaries.
Detail: adds finer irregularity to patch edges.
Seed: rearranges the pattern without changing its other settings.
Invert: exchanges the populated areas and gaps.

Geometry Proximity

Restricts placement around target objects, such as keeping plants away from a house.

1. Select the target object, then Ctrl+click an instance to include the layer in the selection.
2. Click Add Selected under Geometry Proximity. The object is added to the list and the mask is enabled.
3. Set Distance (cm) to define the affected area around the object.
4. Set Transition (cm) to soften the boundary.
5. Choose Behaviour: Repel excludes nearby instances, while Attract keeps instances only near the target.

Click an object's x to remove it. Clear removes all targets added in Unreal. Targets imported from Blender remain and are counted separately above the list.

Curve Proximity

Uses a spline to define a path, road, river margin, or other continuous region.

1. Select the layer and click Draw New Spline. A short, selected spline appears where the viewport is looking.
2. Shape the spline by moving its points. Alt+drag an endpoint to add more points.
3. Select the layer again and set Distance (cm). With Repel behaviour, this clears the specified distance on each side of the spline. At 0, nothing is cleared; 400 creates 4 m of clearance per side.
4. Adjust Transition (cm) to soften the outer boundaries.
5. Choose Behaviour: Attract keeps instances along the spline, while Repel clears them away from it.

To use an existing actor with a Spline component, select it together with the layer and click Add Selected under Curve Proximity. Editing the spline updates the scatter when you release the point.
