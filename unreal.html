Unreal Engine Plugin

Install the plugin, connect Blender, and continue building your environment in Unreal

Beta The ScatterFlow plugin for Unreal Engine is in early development. Features, settings, and interface elements may change between releases.
How it works Install the plugin Step 1: Open the ScatterFlow panel Step 2: Connect to Blender Step 3: Bring your scene over Export to Blender

How it works

The ScatterFlow plugin adds a panel to the Unreal Editor for scene transfer, scatter editing, and environment tools.

Connect Blender and Unreal. Export supported content from Blender's ScatterFlow Export tab directly into the open level, without manually importing files.

Edit scatter layers in Unreal. Each Blender scatter layer arrives as one ScatterFlow actor containing its instances. Select it to adjust density, scale, meshes, or procedural placement without returning to Blender.

Add environment tools. Configure foliage wind, a dynamic sky, weather, water, and ivy. Use Play to explore the level with a supplied character.

Set up both sides of the connection. Install the plugin in your Unreal project as described below. In Blender, use ScatterFlow's Export tab; see Export.

Install the plugin

The plugin requires Unreal Engine 5.8 on Windows, an Unreal project, and ScatterFlow for Blender. Install it separately in each project's Plugins folder.

Install into your project

1. Close the project in the Unreal Editor.

2. Extract ScatterFlow_UnrealPlugin_V1.0.zip, which contains ScatterFlowUnrealSync. Use a short extraction path such as C:\Temp to avoid Windows path-length problems with long filenames.

3. Open the project folder containing the .uproject file. Create a Plugins folder beside it if one does not exist.

4. Move ScatterFlowUnrealSync into Plugins. Confirm that Plugins\ScatterFlowUnrealSync\ScatterFlowUnrealSync.uplugin exists. Avoid an extra nested ScatterFlowUnrealSync folder.

5. Open the project. The plugin is precompiled for Unreal 5.8 on Windows. Its dependencies—PCG, WebSocket Networking, and Procedural Mesh Component—are enabled as part of the setup.

6. Open Edit > Plugins, search for ScatterFlow, and confirm that ScatterFlow Unreal Sync is enabled. It is marked Beta. If you enable it here, click Restart Now.

7. Confirm that the ScatterFlow button appears in the main toolbar, then continue to Step 1.

Updating to a new version

Close Unreal, delete the existing Plugins\ScatterFlowUnrealSync folder, and replace it with the new version using steps 2–4. Remove the old folder first so obsolete files are not left behind.

Update the Blender add-on at the same time to keep both sides on the same release.

If the plugin does not load

Modules are missing or were built for another engine version. This plugin build supports Unreal Engine 5.8. Other engine versions are not supported by this build.

The ScatterFlow toolbar button is missing. Confirm that the plugin is enabled and that its folder is not nested an extra level deep.

Blender cannot connect. Both applications must be open. Check that Blender's connection address matches the plugin's Link Settings; see Step 2.

Step 1: Open the ScatterFlow panel

The ScatterFlow button

Click ScatterFlow in the main toolbar beside the Play controls to open the panel. It is also available from Tools > ScatterFlow Scatter.

The panel opens in a floating window. Move and resize it to fit your workspace; it can remain open while you edit the level.

At the top of the panel:

Play starts a walkthrough using the ScatterFlow character. See Play.
The connection status displays Blender connected with a green indicator when the link is active.
Link Settings opens the Blender connection settings.
The editing line identifies the active selection. With no layer selected, it reads Select a layer to edit it and displays the scene tools. The four icons add water, ivy, weather, or sky.

The panel follows your selection. Select a ScatterFlow layer to edit its settings. Click empty space to return to the scene tools.

Step 2: Connect to Blender

The plugin starts its connection service with Unreal. In Blender's Export tab, select Unreal and click Connect. When connected, the Unreal panel reports Blender connected.

Link Settings

Click Link Settings to view the connection controls. The defaults normally require no changes.

The status line shows the current state, such as Connected — ready. Its tag is CONNECTED, LISTENING while waiting for Blender, or OFFLINE when stopped.

Blender connection URL: the address Blender connects to. It must match the Unreal Link URL in Blender's ScatterFlow preferences. Use Copy URL after changing the port to update Blender's address.

Port: the connection's network port. Change it only when another application is using the same port. Stop the link first; this field is disabled while it is running.

Start with Unreal: starts the connection service when the project opens. Leave it enabled for normal use.

Auto-import scatter exports from Blender: also detects scatter exports saved to disk while the connection was inactive. Exports sent over an active connection arrive regardless of this option.

Live sync edits to Blender: sends changes to linked objects back to Blender as you edit them in Unreal.

Mirror deletes to Blender: also deletes the linked Blender object when you delete it in Unreal. This is disabled by default to avoid unintended deletion of Blender content.

Stop Live Link: stops the connection service.

Switching the options

Click an option's checkbox to enable or disable it. Changes take effect immediately and are retained when you reopen the project.

Enable deletion syncing deliberately. Live sync is useful when refining placement in Unreal, but keep Mirror deletes to Blender disabled unless deletions should also affect the Blender scene.

Stopping and restarting the link

Stop Live Link closes the connection and changes the status to Blender link offline.

Start Live Link opens the service again. The status changes to Waiting for Blender until a connection is established.

Blender does not reconnect automatically. Click Connect in its Export tab again to restore the link.

Step 3: Bring your scene over

Once connected, click Export to Unreal in Blender. Supported content is added to the level currently open in Unreal. See Export for selection and export options.

What arrives

Unreal creates the incoming assets and places the exported scene content in the level.

The Outliner identifies the resulting actors. For a meadow with three scatter layers and two selected boulders, these include:

SF Terrain - Meadow: the scatter terrain as a mesh with its material and collision.
SF Scatter - Trees, SF Scatter - Bushes, and SF Scatter - Rocks: one actor per scatter layer, containing that layer's instances.
Boulder 1 and Boulder 2: the individually selected Blender objects.

Subsequent exports update the existing actors instead of adding duplicates.

Layer settings can retain Unreal-side edits. On re-export, settings changed in Blender replace their corresponding values; unchanged Blender settings leave Unreal adjustments intact. See Scatter Layers for the separate behaviour of the mesh list.

Select a layer to edit it

Click an instance in the viewport to select its entire layer. The panel displays that layer's controls, with a label such as Editing Trees.

Ctrl+click an instance from another layer to edit both together. The label changes to Editing 2 layers, and adjustments apply to both.

Click empty space to deselect and return to the scene tools.

Export to Blender

Send actors back to Blender

Select actors in the level, expand Export, and click Export to Blender.

Actors originally exported from Blender update their existing Blender objects. Meshes created in Unreal arrive as new Blender meshes with their materials.

Use this to transfer an engine-created prop, such as a crate, into the Blender scene.

Live sync

Enable Live sync edits to Blender in Link Settings to send edits to linked actors immediately, without manually exporting each change.

For example, repositioning a linked crate in Unreal also updates its position in Blender.
