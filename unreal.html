Unreal Engine Plugin

Install the plugin, connect Blender, and continue building your environment in Unreal

Beta The ScatterFlow plugin for Unreal Engine is in early development. Features, settings, and interface elements may change between releases.

How it works

The ScatterFlow plugin adds a panel to the Unreal Editor. Use it to bring your Blender scene over, edit scatter layers, and add environment tools.

Connect Blender and Unreal. Send content from Blender's ScatterFlow Export tab straight into the open level. There is no need to import files by hand.

Edit scatter layers in Unreal. Each Blender scatter layer arrives as one ScatterFlow actor that holds its instances. Select it to change density, scale, meshes, or placement without going back to Blender.

Add environment tools. Add foliage wind, a dynamic sky, weather, water, and ivy. Use Play to walk around the level with a ready-made character.

Set up both sides of the connection. Install the plugin in your Unreal project, as described below. In Blender, use ScatterFlow's Export tab.

Install the plugin

The plugin needs Unreal Engine 5.8 on Windows and ScatterFlow for Blender. Install it into each project's Plugins folder separately.

Install into your project

Close the project in Unreal first, then:

1. Extract ScatterFlow_UnrealPlugin_V1.0.zip to a short path, such as C:\Temp. Long paths can cause problems on Windows.

2. In the project folder that holds the .uproject file, create a Plugins folder if there is not one already.

3. Move the ScatterFlowUnrealSync folder into Plugins. The file Plugins\ScatterFlowUnrealSync\ScatterFlowUnrealSync.uplugin should exist, without an extra ScatterFlowUnrealSync folder in between.

Open the project. The plugin comes precompiled, and the plugins it depends on are turned on for you.

In Edit > Plugins, check that ScatterFlow Unreal Sync is enabled. If you have to enable it, click Restart Now. Once it is running, the ScatterFlow button is in the main toolbar. Continue to Step 1.

Updating to a new version

Close Unreal and delete the old Plugins\ScatterFlowUnrealSync folder, then install the new version with steps 1–3. Removing the old folder first makes sure no outdated files are left behind.

Update the Blender add-on at the same time, so both sides are on the same release.

If the plugin does not load

Modules are missing or were built for another engine version. This build of the plugin supports Unreal Engine 5.8 only.

The ScatterFlow toolbar button is missing. Check that the plugin is enabled and that its folder is not nested one level too deep.

Blender cannot connect. Both programs must be open. Check that Blender's connection address matches the plugin's Link Settings. See Step 2.

Step 1: Open the ScatterFlow panel

The ScatterFlow button

Click ScatterFlow in the main toolbar, next to the Play controls, to open the panel. It is also under Tools > ScatterFlow Scatter. The panel is a floating window that can stay open while you work.

The top of the panel holds the Play button, which starts a walkthrough with the ScatterFlow character (see Play). Next to it are the connection status and the Link Settings button, which opens the Blender connection settings.

When no layer is selected, the panel shows the scene tools. Its four icons add water, ivy, weather, or sky.

The panel follows your selection. Select a ScatterFlow layer to edit its settings. Click empty space to return to the scene tools.

Step 2: Connect to Blender

The connection starts when Unreal opens. In Blender's Export tab, click the Unreal button, then click Connect. The panel's status shows when Blender is connected.

Link Settings

Click the Link Settings button to show the connection controls. The defaults work for most projects. The status line shows whether the link is connected, waiting for Blender, or offline.

Blender connection URL is the address Blender connects to. It must match the Unreal Link URL in Blender's ScatterFlow preferences. If you change the port, click the Copy URL button to update the address in Blender.

Only change Port if another program is using the same one. Stop the link first, because the field is locked while the link is running.

The Start with Unreal checkbox starts the connection when the project opens. Leave it on for normal use.

Turn on Auto-import scatter exports from Blender to also pick up scatter exports that were saved while the connection was off. Exports sent over a live connection always arrive.

Turn on Live sync edits to Blender to send your changes to linked objects back to Blender as you make them.

The Mirror deletes to Blender checkbox also deletes the linked Blender object when you delete it in Unreal. It is off by default, so you do not delete Blender content by accident.

The Stop Live Link button stops the connection.

Switching the options

Options take effect as soon as you change them, and they are kept when you reopen the project.

Turn on deletion syncing only on purpose. Live sync is useful when you refine placement in Unreal. Keep Mirror deletes to Blender off unless deleting in Unreal should also delete in Blender.

Stopping and restarting the link

Click the Stop Live Link button to close the connection, and the Start Live Link button to open it again.

Blender does not reconnect on its own. Click Connect in its Export tab again to restore the link.

Step 3: Bring your scene over

Once connected, click Export to Unreal in Blender. Supported content is added to the level that is open in Unreal. See Export for what to export and how.

What arrives

Unreal creates the incoming assets and places your scene in the level. In the Outliner:

The scatter surface becomes a terrain mesh with its material and collision, such as SF Terrain - Meadow.
Each scatter layer becomes one actor holding that layer's instances, such as SF Scatter - Trees.
Objects you selected individually in Blender keep their own names.

Exporting again updates the existing actors instead of adding duplicates.

Layer settings can keep your Unreal edits. When you export again, settings you changed in Blender replace the Unreal values. Settings you did not change in Blender keep your Unreal adjustments. The mesh list works differently; see Scatter Layers.

Select a layer to edit it

Click an instance in the viewport to select its whole layer and show its controls in the panel.

Ctrl+click an instance from another layer to edit both layers together.

Click empty space to go back to the scene tools.

Export to Blender

Send actors back to Blender

Select actors in the level, expand the Export section, then click Export to Blender.

Actors that came from Blender update their original Blender objects. Meshes made in Unreal arrive as new Blender meshes with their materials, so you can bring a prop built in Unreal into your Blender scene.

Live sync

Turn on Live sync edits to Blender in Link Settings to send edits to linked actors straight away, without exporting each change.

For example, moving a linked object in Unreal also moves it in Blender.
