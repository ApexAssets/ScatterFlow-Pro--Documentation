Godot Plugin

Install the plugin, connect Blender, and continue building your environment in Godot

Beta ScatterFlow Link for Godot is in early development. Features, settings, and interface elements may change between releases.

How it works

ScatterFlow Link adds a ScatterFlow Pro dock to the Godot editor. Use it to bring scenes over from Blender, edit scatter layers, and add environment tools.

Connect Blender and Godot. Send objects, materials, lights, and scatter layers from Blender straight into your open Godot scene. There are no files to import by hand.

Edit scatter layers in Godot. Each Blender layer becomes a layer node under its terrain. Select one to change its density, scale, meshes, or placement without going back to Blender.

Add environment tools. Add wind, water, ivy, sky, and weather. Use Play to walk through the scene with the supplied character.

Set up both sides of the connection. Install the plugin in your Godot project, and use the Export tab of ScatterFlow in Blender.

Install the plugin

The plugin needs Godot 4.7, a Godot project, and ScatterFlow for Blender. Install it into each project you want to use it in.

Install into your project

1. Extract the plugin .zip and copy its addons folder into your project folder, next to project.godot. If the project already has an addons folder, put scatterflow inside it with your other add-ons.

2. Open the project in Godot and let it finish importing. Then enable ScatterFlow Link in the Project > Project Settings > Plugins tab. The ScatterFlow Pro dock appears next to the Inspector.

3. Reload the project once from the Project > Reload Current Project menu. ScatterFlow raises the Global Shader Variables > Buffer Size project setting for large scatter scenes, and the change needs a reload.

4. Open a 3D scene and save it. The plugin needs a saved scene to receive content from Blender. Then continue to Step 1.

Use Forward+ or Mobile for ScatterFlow water. The water does not display correctly with the Compatibility renderer. New projects use Forward+ by default. The active renderer is shown in the editor's upper-right corner.

Updating to a new version

Close Godot, delete the project's addons\scatterflow folder, and copy in the new one. When you reopen the project, ScatterFlow rebuilds its materials once if the new version needs it.

Update the Blender add-on at the same time, so both sides are on the same release.

If the plugin does not load

ScatterFlow Link is missing from the Plugins list. The plugin must be at addons\scatterflow directly inside the project. Check for an extra folder, such as addons\addons\scatterflow or one named after the download.

The dock does not appear. Make sure Enable is ticked for the plugin, then reload the project.

Blender cannot connect. Both programs must be open, and Blender's connection address must match the one in Plugin Settings. See Step 2.

Step 1: Open the ScatterFlow Pro dock

The ScatterFlow Pro tab

Open the dock from the ScatterFlow Pro tab next to the Inspector. When no ScatterFlow node is selected, it shows the scene tools in these sections.

Global Wind: wind for ScatterFlow plants across the project.
Play: walk through the scene with the ScatterFlow character.
Export: send selected nodes back to Blender.
Plugin Settings: the Blender connection.

The four icons at the top right add water, ivy, sky, or rain. Water and ivy are placed where the 3D view is looking. Each tool has its own page, including Wind and Play.

The Sky section only appears when the scene has an SF Sky. Weather appears when there is a sky, or when rain or snow is on.

The dock follows your selection. Select a ScatterFlow layer, water, or ivy node to see its controls. Click empty space or any other node to get back to the scene tools.

Step 2: Connect to Blender

The connection starts by itself when you open the Godot editor. To link the two, click the Godot button in Blender's Export tab, then click Connect.

Plugin Settings

The Plugin Settings section, at the bottom of the dock, holds the connection controls and the options for linked objects.

Blender Link

A green Linked to Blender status means you are connected. Waiting for Blender means Godot is ready, but Blender has not connected yet.

The address shown here must match the Godot Link URL field in Blender's ScatterFlow preferences, under Settings > Export > Godot. The defaults already match. If you change the address, click the Copy button and paste it into Blender.

Port: change it only if another program already uses it. Then click Restart and update the Link URL in Blender to match.

Objects

Live Sync Edits to Blender: when this checkbox is on, it sends moves, rotations, and scale changes on linked nodes back to Blender, including linked lights and cameras.

Deleting Here Deletes in Blender: when this checkbox is on, deleting a linked node in Godot also deletes its Blender object. It is off by default, so you do not lose Blender content by accident.

The last status line shows the connection's latest activity.

Restarting the link

Clicking Restart restarts the connection and drops the current link to Blender.

Blender does not reconnect on its own. Click Connect in its Export tab again.

Restart only when needed. Use it after changing the port, or if the connection stops responding. Otherwise the connection starts by itself with the editor.

Step 3: Bring your scene over

Exporting from Blender

Once connected, click Export to Godot in Blender's ScatterFlow Export tab.

Godot builds the scene in two passes. First come the objects, meshes, and materials, under a node named after your Blender scene. Then each terrain becomes an SF Terrain node with collision, with its scatter layers under it.

Save the Godot scene when both passes have finished.

Re-export to update the scene. Existing objects are updated instead of duplicated, and scatter layers are rebuilt from the new Blender result.

Export to Blender

Sending nodes back to Blender

Select the nodes you want to send, such as meshes, lights, cameras, or empty nodes. Then click Export to Blender in the Export section.

Linked nodes update their Blender objects. New nodes create new Blender objects and stay linked for later exports and live edits.

Live sync and deleting

Turn on Live Sync Edits to Blender in Plugin Settings to send edits as you make them. Moving a linked object in Godot then moves it in Blender too.

Turn on Deleting Here Deletes in Blender only if deleting a node in Godot should also delete its Blender object.

Recorded with ScatterFlow Link 1.8.0 in Godot 4.7.2, linked to ScatterFlow 1.0.9 in Blender 5.2.2.
