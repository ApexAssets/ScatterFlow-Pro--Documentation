Godot Plugin

Install the plugin, connect Blender, and continue building your environment in Godot

Beta ScatterFlow Link for Godot is in early development. Features, settings, and interface elements may change between releases.

How it works

ScatterFlow Link adds the ScatterFlow Pro dock to the Godot editor for scene transfer, scatter editing, and environment tools.

Connect Blender and Godot. Export supported objects, materials, lights, and scatter layers from Blender directly into the open Godot scene, without manually importing files.

Edit scatter layers in Godot. Each Blender layer arrives as a ScatterFlow layer node beneath its terrain. Select it to adjust density, scale, meshes, or procedural placement without returning to Blender.

Add environment tools. Configure wind, water, ivy, sky, and weather. Use Play to explore the scene with the supplied character.

Set up both sides of the connection. Install the plugin in the Godot project as described below. In Blender, use ScatterFlow's Export tab; see Export.

Install the plugin

The plugin requires Godot 4.7, a Godot project, and ScatterFlow for Blender. Install it separately in each project's addons folder.

Install into your project

1. Extract ScatterFlow_Godot Plugin_V1.0.zip. It contains an addons folder with scatterflow inside.

2. Copy addons into the project folder containing project.godot. If the project already has an addons folder, place scatterflow inside it beside your other add-ons. Confirm that addons\scatterflow\plugin.cfg exists directly within the project.

3. Open the project in Godot and allow the plugin files to import.

4. Open Project > Project Settings > Plugins and enable ScatterFlow Link using its Enable checkbox.

5. Confirm that the ScatterFlow Pro dock appears beside the Inspector.

6. The Output panel reports that ScatterFlow increased Global Shader Variables > Buffer Size, a project setting needed for large scatter scenes. Apply the change by restarting once with Project > Reload Current Project.

7. Open a 3D scene and save it before exporting from Blender. The plugin needs a saved scene to receive content. Continue to Step 1.

Use Forward+ or Mobile for ScatterFlow water. The water effect relies on scene depth and is not displayed correctly with the Compatibility renderer. New projects use Forward+ by default; check the active renderer in the editor's upper-right corner.

Updating to a new version

Close Godot, delete the project's addons\scatterflow folder, and replace it using steps 1–2. Reopen the project. ScatterFlow rebuilds materials once when required by the new version.

Update the Blender add-on at the same time to keep both sides on the same release.

If the plugin does not load

ScatterFlow Link is missing from the Plugins list. Check that the path is addons\scatterflow directly inside the project, not addons\addons\scatterflow or an extra folder named after the download.

The dock does not appear. Confirm that Enable is selected for the plugin, then reload the project.

Blender cannot connect. Both applications must be open, and Blender's connection address must match Plugin Settings. See Step 2.

Step 1: Open the ScatterFlow Pro dock

The ScatterFlow Pro tab

Click ScatterFlow Pro beside the Inspector to display the dock.

With no ScatterFlow node selected, the dock reads Select a scatter layer to edit it. and shows the scene tools. Click a section title to expand or collapse it.

Global Wind: wind settings for ScatterFlow plants throughout the project.
Play: starts a walkthrough with the ScatterFlow character.
Export: sends selected nodes back to Blender.
Plugin Settings: configures the Blender connection.

The four icons in the upper-right corner add water, ivy, sky, or rain. Water and ivy are placed where the 3D view is looking. See the Water, Ivy, Sky, Weather, Wind, and Play pages for their workflows.

Sky appears when the scene contains an SF Sky. Weather appears when rain or snow is active, or when a sky is present.

The dock follows your selection. Select a ScatterFlow layer, water, or ivy node to show its controls. Click empty space or a non-ScatterFlow node to return to the scene tools.

Step 2: Connect to Blender

The plugin starts its connection service with the Godot editor. In Blender's Export tab, select Godot and click Connect. The dock reports Linked to Blender when connected.

Plugin Settings

Expand Plugin Settings at the bottom of the dock. It contains connection controls and options for linked objects.

Blender Link

The status shows a green indicator and Linked to Blender while connected. Waiting for Blender means the service is running but no Blender connection is active.

The displayed address must match Godot's Link URL in Blender under ScatterFlow preferences > Settings > Export > Godot. The defaults match. Use Copy to transfer a changed address to Blender.

Port: the network port, 18778 by default. Change it only when another program uses the same port. Click Restart afterward and update Blender's Link URL to use the new port.

Objects

Live Sync Edits to Blender: sends position, rotation, and scale changes for linked nodes back to Blender. It also synchronizes edits to linked lights and cameras.

Deleting Here Deletes in Blender: removes the linked Blender object when its Godot node is deleted. This is disabled by default to protect Blender content from unintended deletion.

The final status line reports the connection's most recent activity.

Restarting the link

Restart closes and reopens the service on the displayed port. The existing Blender connection is dropped, and the status returns to Waiting for Blender.

Blender does not reconnect automatically. Click Connect in its Export tab again to restore the link.

Restart only when needed. Use it after changing the port or when the connection stops responding. The service starts automatically with the editor during normal use.

Step 3: Bring your scene over

Exporting from Blender

With the connection active, click Export to Godot in Blender's ScatterFlow Export tab. Godot builds the scene in two passes, each shown in a viewport progress card.

Importing from Blender: imports objects, meshes, and materials beneath a node named after the Blender scene.

Importing Scatter System from Blender: creates an SF Terrain node for each terrain, with collision, and adds its scatter layers beneath it.

When both progress cards reach 100%, save the Godot scene.

Re-export to update the scene. Existing objects are updated in place instead of duplicated. Scatter layers are rebuilt using the new Blender result.

Export to Blender

Sending nodes back to Blender

Select the nodes to send, including meshes, lights, cameras, or empty nodes. Expand Export and click Export to Blender.

Linked nodes update their existing Blender objects. New nodes create Blender objects and become linked for subsequent exports and live edits.

Live sync and deleting

Enable Live Sync Edits to Blender under Plugin Settings > Objects to synchronize edits immediately. Moving a linked object in Godot also moves its Blender counterpart.

Enable Deleting Here Deletes in Blender only when deleting a Godot node should also remove its Blender object.

Recorded with ScatterFlow Link 1.8.0 in Godot 4.7.2, linked to ScatterFlow 1.0.9 in Blender 5.2.2.
