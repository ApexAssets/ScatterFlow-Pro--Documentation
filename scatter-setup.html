Surface, Instances and Scattering

Control where a layer scatters, which objects it uses, and how densely they are placed

Surface Instances Scattering

Surface, Instances, and Scattering are the first three sections below the System List. All three apply to the selected layer.

Surface

Choose the geometry that receives the layer's instances. This can be the emitter itself, another object, or a collection of objects.

Type

  • Default Emitter Object

Emitter Object scatters on the current emitter. Its name appears below the setting as a read-only reference.

Single Surface scatters on another object selected in the field below. Use it to place a layer on a specific surface, such as one boulder, without changing its emitter.

Multiple Surfaces scatters on all objects in the selected collection. For example, select a collection of boulders to cover every rock while leaving the surrounding terrain clear.

The layer remains in its emitter's System List regardless of which surface it uses.

Collection missing from the picker? Multiple Surfaces lists collections directly beneath the Scene Collection. Move a nested collection to that level to make it available.

Instances

Choose the objects the layer places on its surface.

Single Instance

Scatters one source object. Select it in the field below Type, or use the eyedropper.

Replacing the source object preserves the scatter positions. Use this to compare a tree, rock, or bush in the same layout without changing the distribution.

Multiple Instances

Scatters a mix of objects from a collection. Set Type to Multiple Instances and select the collection; each scatter point uses one of its objects.

Add or remove objects in the collection to change the available mix. The layer updates automatically.

Scattering

Control the placement method, instance density, and spacing.

Type: Procedural or Manual

  • Default Procedural

Procedural distributes instances across the surface according to settings such as Density and masks. Changing a setting updates the scatter automatically.

Manual starts with an empty layer and lets you place instances with brushes. It replaces Density and the Factor buttons with a Manual Mode section containing Start Placing. See Manual Mode for the available brushes.

Use Procedural for coverage that should respond to changes in your setup. Use Manual for deliberate placement, such as a hero tree or a carefully arranged path edge. Both approaches can be combined by creating one layer of each with the same source objects.

Switching modes preserves manual placements. Returning to Procedural restores the automatic scatter. Switching back to Manual restores your hand-placed instances.

Density / m²

Sets the number of instances per square metre of surface. A value of 1 on a 40 m × 40 m surface produces approximately 1,600 instances before masks remove any.

Use higher densities for small plants and lower densities for trees. Adjust Density to compare sparse and dense coverage.

Seed

  • Default 0

Changes the random arrangement without changing the number of instances.

Enter a value or click the dice button to choose a random seed. Different seeds help prevent separate layers from placing instances at matching positions.

Factor

  • Default 2.00

Controls the amount used by the four Density adjustment buttons: multiply, divide, add, and subtract.

With Factor set to 2, * doubles Density and / halves it. The + and − buttons add or subtract the Factor value itself. For sparse layers, use a smaller Factor, such as 0.1, before adding or subtracting.

Limit Self-Collision

  • Default off
  • Minimum Distance 0 m

Enforces minimum spacing between instances in the same layer. Enable the option and set Minimum Distance to the closest allowed spacing.

Instances that violate the spacing are removed. Increasing Minimum Distance therefore reduces the number of instances, and at larger values spacing becomes the limiting factor rather than Density.

This setting only checks the current layer. To control spacing between different layers, use Ecosystem.
