Surface, Instances and Scattering

Control where a layer scatters, which objects it uses, and how densely they are placed

Surface Instances Scattering

Surface, Instances, and Scattering are the first three sections below the System List. They all apply to the selected layer.

Surface

Choose what the layer scatters on: the emitter itself, another object, or a collection of objects.

Type

  • Default Emitter Object

In the Type menu, Emitter Object scatters on the current emitter.

Single Surface scatters on another object you choose. Use it to put a layer on one surface, such as a boulder, without changing its emitter.

Multiple Surfaces scatters on every object in a collection. For example, choose a collection of boulders to cover the rocks and leave the terrain around them clear.

Whatever surface it uses, the layer stays in its emitter's System List.

Collection missing from the picker? Multiple Surfaces only lists collections directly under the Scene Collection. Move a nested collection up to that level to use it.

Instances

Choose the objects the layer places on its surface.

Single Instance

Scatters one object. Choose it in the field below Type, or pick it with the eyedropper.

Swapping the object keeps the same positions, so you can compare a tree, rock, or bush in the same layout.

Multiple Instances

Set Type to Multiple Instances to scatter a mix of objects from a collection. Each point uses one of the collection's objects.

Add or remove objects in the collection to change the mix. The layer updates automatically.

Scattering

Choose how instances are placed, how many there are, and how far apart they sit.

Type: Procedural or Manual

  • Default Procedural

Procedural spreads instances across the surface based on settings such as Density and masks. It updates whenever you change a setting.

Manual starts empty and lets you place instances with brushes. Click the Start Placing button in the Manual Mode section, which takes the place of Density and the Factor buttons. See Manual Mode for the brushes.

Use Procedural for coverage that follows changes to your setup, and Manual for deliberate placement, such as a hero tree or a path edge. To combine both, make one layer of each with the same objects.

Switching modes preserves manual placements. Going back to Procedural restores the automatic scatter, and switching to Manual again brings back your hand-placed instances.

Density / m²

Sets how many instances are placed per square metre of surface, before any masks remove some.

Use higher values for small plants and lower values for trees.

Seed

  • Default 0

Changes the random arrangement without changing how many instances there are.

Type a value, or click the dice for a random one. Give separate layers different seeds so they do not place instances in the same spots.

Factor

  • Default 2.00

Sets the step used by the four Density buttons: multiply, divide, add, and subtract.

With Factor at 2, * doubles Density and / halves it. + and − add or subtract the Factor itself, so use a small Factor, such as 0.1, on sparse layers.

Limit Self-Collision

  • Default off
  • Minimum Distance 0 m

Keeps instances in the same layer a minimum distance apart. Set Minimum Distance to the closest they may be.

Instances that are too close are removed, so a larger Minimum Distance means fewer instances. At large values, spacing rather than Density decides how many you get.

It only checks the current layer. To space out different layers, use Ecosystem.
