Texture Masks

Shape a scatter layer with natural patches, rows, grids, or an image mask

Noise Lines Tiles Image Transform

Texture masks apply a pattern across the scatter surface to control where instances appear and how they scale near boundaries. Each mask has its own checkbox, and multiple masks can be combined.

Noise

Creates irregular patches with gaps between them. Use it for vegetation that should form natural clusters rather than cover the surface uniformly.

Falloff: Min and Max

  • Min 0.4
  • Max 0.6

The noise pattern has a value from 0 to 1 at each point. Instances are excluded below Min, reach full size above Max, and scale gradually between the two.

Raise both thresholds to reduce coverage, or lower them to fill more of the surface. Bring the values closer for sharper boundaries; separate them for a wider scale transition.

Seed and Scale

  • Seed 0
  • Scale 1.0

Seed changes the arrangement of patches while preserving the other pattern settings.

Scale controls pattern frequency. Lower values create fewer, larger patches; higher values create more, smaller patches. Values around 0.1–0.3 are a useful starting point for a large terrain.

Detail, Roughness, Lacunarity and Distortion

  • Detail 2
  • Roughness 0.5
  • Lacunarity 2
  • Distortion 0

Detail adds smaller-scale patterns to the main noise. At 0, patch boundaries are smooth and rounded. Higher values create more irregular edges.

Roughness sets the strength of the finer patterns. Lacunarity controls how much smaller each successive pattern becomes. Both depend on Detail being above 0.

Distortion warps the noise into swirls and elongated shapes.

Lines

Creates parallel bands. Use it for crop rows, vineyards, ploughed fields, or planted borders.

Falloff: Min and Max

  • Min 0.3
  • Max 0.6

These thresholds work as they do for Noise. Increasing Min narrows the planted bands and widens the gaps. Max controls the transition to full-size instances along their edges.

Scale and Phase Offset

  • Scale 0.6
  • Phase Offset 0

Scale controls the number of rows. Lower values produce fewer, wider rows; higher values produce more, narrower rows.

Phase Offset shifts the rows sideways without changing their spacing. Use it to align them with a fence, path, or another layer.

Distortion and its detail

  • Distortion 0
  • Detail 2
  • Detail Scale 1
  • Detail Roughness 0.5

Distortion bends the rows away from straight lines, creating less regular planting patterns.

The other settings shape this variation and have no effect when Distortion is 0. Detail adds finer variations, Detail Scale controls their size, and Detail Roughness controls the strength of the finest changes.

Tiles

Creates a rectangular grid separated by gaps. Use it for planting beds, garden plots, paving, or other regularly spaced arrangements.

Scale and Gap Size

  • Scale 2.0
  • Gap Size 0.05

Scale controls the number of tiles. Lower values create fewer, larger tiles; higher values create more, smaller tiles. The default of 2 produces very small tiles on most surfaces, so lower it first if the pattern is difficult to see.

Gap Size sets the width of the empty strips between tiles, from nearly zero to 0.125.

Width and Height

  • Width 0.5
  • Height 0.5

Set the proportions of each tile. Equal values produce squares. Increase Width for elongated beds, or decrease Height for narrow strips.

Image

Uses an image as the mask. White areas retain instances, and black areas exclude them. Create a mask in an image editor or use a graphic, such as a logo, to define the scatter pattern.

Image and Bounds

  • Default off
  • Bounds Clip

Enable Image, click the folder button, and choose an image file. The layer remains empty until an image is selected.

Bounds controls what happens outside the image. Clip displays it once and leaves the rest of the surface empty. Repeat tiles it across the surface.

Use small instances and sufficient density for detailed shapes. Increase Density and reduce Uniform Scale if the image outline looks coarse.

Min, Max, Sharpen and Invert

  • Min 0
  • Max 1
  • Sharpen off
  • Invert off

Invert reverses the mask, filling the areas that would otherwise be empty.

Min and Max control grayscale transitions. Instances are excluded below Min, full size above Max, and scaled between them. Sharpen makes soft boundaries more distinct.

These three controls have little effect on a purely black-and-white image because it has no intermediate grayscale values. Use them with gradients, photographs, or softly painted masks.

Location, Rotation and Scale

  • Scale 1 / 1 / 1

Location moves the image across the surface in metres. Rotation changes its orientation; adjust Z to rotate it across the ground.

Scale works in reverse: increasing the value makes the image smaller, while decreasing it makes the image larger. At 1, the image is approximately 10 m wide. Different X and Y values stretch the mask independently.

The image retains its original aspect ratio unless you stretch it with separate axis values.

Transform

Noise, Lines, and Tiles each include transform controls for positioning and orienting their patterns.

Location, Rotation and Scale

Location moves the pattern across the surface. It shifts the mask, not the underlying instance positions.

Scale stretches the pattern along individual axes. Stretching noise along X, for example, turns rounded patches into elongated bands.

Rotation changes the pattern's orientation. Use Z to rotate it across the ground.

On Lines

Use Rotation to set the direction of the rows. Location shifts their position, similarly to Phase Offset.

On Tiles

Use Location to align the grid with the surface boundaries and Rotation to change its angle.

Group Texture Masks

Select a group to access Group Texture Masks. The same pattern is applied to every layer in the group, allowing them to share patches, rows, or a grid.
