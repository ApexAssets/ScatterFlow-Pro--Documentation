ScatterFlow documentation / Scatter

Biomes

Populate a surface with a ready-made set of editable scatter layers

Biome Browser Finding a biome Importing Large biomes Your own biomes GScatter environments

A biome combines multiple scatter layers with their assets, densities, and masks already configured. Importing a biome adds its layers to the current emitter as a group.

After importing, you can adjust each layer, modify the group, or combine layers from different biomes to build your own environment.

Biome Browser

Opening the browser

Choose an emitter and click Open Biome Browser. Move the cursor over the editor you want to use; it highlights blue. Click to replace that editor with the browser, or press Esc or right-click to cancel.

A tall area beside the viewport keeps the browser, scene, and ScatterFlow controls accessible together. Allow enough width to view multiple previews comfortably.

Size adjusts preview size from 3 to 14.

Closing it

Click Exit Biome Panel or the red cross beside Size. The editor returns to its previous view.

Finding a biome

Search, Categories and Favorites

Search filters biomes by name as you type. For example, enter “meadow” to find matching biomes.

Under Categories, expand ScatterFlow to browse Desert, Forest, Lawn, Meadow, Trash, Tropical, Wasteland, and Wetland. Select a category to filter the results, or choose ALL to show everything. Other installed packs have their own folders.

Click a biome's star to mark it as a favourite, then select Favorites to view starred biomes. Favorites are saved between sessions.

The refresh arrows beside Size reload the biome folder. Use them after installing or exporting a biome.

Importing

A whole biome

Click a biome's name to add all its layers to the current emitter. They arrive in a group named after the biome. For example, Forest Floor_V1 adds ten layers, including flowering plants, leaf litter, and fallen sticks.

Use the group's controls to hide, duplicate, or adjust the biome as a whole. Select individual layers for more specific changes, or select the group to use Group Scattering.

Importing the biome onto another emitter reuses its plants already present in the file.

Single layers

Click the arrow beside a biome's name to display its Individual Layers, then click + beside the layer you want to import.

Individually imported layers are not grouped. Use this to take a particular plant from a biome or combine selected layers from several biomes.

Large biomes

The Large Biome Import prompt

ScatterFlow estimates the number of instances before importing. If the estimate exceeds 100,000, it asks how to handle viewport density. For example, Dandelion Meadow produces approximately 115,000 instances on a 25 m square emitter.

Yes, use adaptive safety imports the layers hidden in the viewport and enables Decrease Viewport Density at the displayed percentage. Render density remains unchanged.

No, keep full viewport density imports the biome without these viewport reductions. Use it when your system can handle the estimated instance count.

After an adaptive-safety import, enable the layers' visibility to view the biome. Adjust Viewport Density as needed to balance coverage and responsiveness.

Nothing visible after importing? Adaptive safety starts layers hidden. Use each layer's monitor icon or the group's eye icon to show them. If the result looks too sparse, increase Viewport Density in Optimization.

Your own biomes

Save your scatter setups as biomes to reuse them in other files.

Export Biome

Open the arrow menu below the System List buttons and choose Export Biome. The command is available when the emitter contains at least one layer. It exports every layer in that emitter's list, including its settings.

Name sets the biome's display name in the Biome Browser. It initially uses the scene name.

Category determines its folder in the browser's Categories list.

Export Path sets the save location. The export contains a .blend file with the assets and a matching .json file describing the layers. Save them in your biomes folder to make the biome available in the browser.

Preview Image optionally supplies the browser thumbnail. It is copied alongside the other files.

Click OK to export.

Refresh after exporting. Click the Biome Browser's refresh arrows to display the new biome.

GScatter environments

ScatterFlow can import Graswald GScatter environments (.gscatter files) as biomes without the GScatter add-on. Imported environments become ordinary ScatterFlow layers that you can edit with ScatterFlow's controls.

Download the environment, install its file once through the Content Installer, then import it from the Biome Browser whenever needed.

Where to get GScatter environments

GScatter environments are available from the Gscatter store at store.gscatter.com. Sign in with a Graswald account and download an environment. The download is a .gscatter file, such as BeeMeadow_x441g_DryCloverField.gscatter.

Each file includes the environment's scatter setup, plants, and textures. Files are often 250 MB–1 GB. Keep the original download to reinstall it or use it on another computer.

Environments from other stores use the same workflow when supplied as .gscatter files.

Check the licence supplied with each environment before using its assets commercially.

The Biome Browser requires an environment, not a single plant. A .gscatter file containing only a plant can install successfully but has no scatter layers to display as a biome.

Installing a .gscatter file

1. Open Edit > Preferences > Add-ons, find ScatterFlow, and expand its preferences.

2. Check Content Library Folder in the Content Installer. Use the same folder as your existing ScatterFlow content. If no folder is set, choose one with sufficient disk space; installation remains disabled until a location is selected.

3. Click Install Content Files, select the .gscatter download, and click Install ScatterFlow / GScatter Content. You can select multiple files and combine .gscatter, .zip, .rar, and .blend files in one installation.

4. Follow the status bar while installation runs. Large files are extracted in the background, leaving Blender usable. Press Esc to cancel. The completion message reports the result, for example Installed 1 content file(s): 30 new file(s), 0 existing file(s) kept.

5. Check the GScatter entry in the Content Installer. It reports the installed pack count, such as 1 pack(s).

Files are extracted into ScatterFlow_GScatter\GScatterPacks within the Content Library Folder, in a subfolder named after the download. Reinstalling the same file keeps existing content and restores missing files.

Importing a GScatter environment

Choose an emitter and open the Biome Browser. Select GScatter under Categories to display installed environments. They share one category without subcategories. Search and Favorites work as they do for other biomes.

Expand an environment's Individual Layers to import selected layers with +. Each original GScatter scatter system becomes one layer; Dry Clover Field, for example, contains six.

Click the environment's name to import the full setup. A progress window reports the layers being added, and the resulting layers are grouped under the environment's name.

Large imports use the same instance estimate and adaptive-safety prompt as other biomes.

What carries over, and what is approximated

GScatter builds scatter systems from stacks of effects. ScatterFlow converts those effects to the closest available ScatterFlow settings. The result resembles the original environment but may not match it exactly.

Carried over: plants and their variations, density, seed, base scale, random scale, random rotation, and surface alignment.

Approximated: multiple GScatter noise masks are represented by one noise mask using the same detail and seed, with density reduced to account for the original masked areas. GScatter's percentage-based alignment becomes enabled surface alignment when the original value is at least halfway.

Not imported: the GScatter terrain generator and effects without a ScatterFlow equivalent.

Once imported, the layers no longer depend on GScatter. Adjust them using ScatterFlow's density, masks, slope and height rules, and other controls.

When something goes wrong

The Install button is disabled. Choose a Content Library Folder first.

“GScatter package has no product.json content.” The file may not be a GScatter package, or the download may be incomplete. Download it again and compare its size with the store listing.

“The selected archive is not ZIP-compatible.” The file is damaged or incomplete. Download it again.

The environment is missing from the Biome Browser. Refresh the browser and select the GScatter category. Check that the Content Installer reports at least one GScatter pack and that the file contains an environment rather than a single plant.

“N missing collection(s)” after importing. Required plants were not found, so their layers were skipped. Reinstall the file to restore missing content. If the environment depends on another Graswald product, install that product's .gscatter file as well.

“Choose an OpenScatter emitter before importing the GScatter environment.” Select an Emitter at the top of the ScatterFlow panel.

Import or viewport performance is slow. GScatter environments can be dense. Try a smaller emitter, accept adaptive safety, or reduce density on the heaviest layers. See Optimization.
