Biomes

Populate a surface with a ready-made set of editable scatter layers

Installing biome packs Biome Browser Finding a biome Importing Large biomes Your own biomes GScatter environments

A biome is a ready-made set of scatter layers, with the assets, density, and masks already set up. Importing one adds its layers to your emitter as a group, which you can then adjust like any other layers.

Installing biome packs

Biome packs are installed once, from ScatterFlow's preferences. Install the content pack first, since the biomes use its models.

Install a biome pack

In ScatterFlow's preferences, choose a folder in the Biomes section, then click the Install biome packs button and choose the pack. For the full setup, see Install the biomes.

Once installed, the biomes are listed in the Biome Browser, sorted into categories.

To update a pack, delete its folder first, then install the new version.

Biomes from older versions

Biomes saved with earlier versions of ScatterFlow still show up in the Biome Browser and import as before. New exports use the .flow format.

Biome Browser

Opening the browser

Choose an emitter, click the Open Biome Browser button, then click the editor you want to replace with the browser. The editor under your cursor is highlighted in blue. Press Esc or right-click to cancel.

A tall area next to the viewport works best, so you can see the browser and the ScatterFlow controls side by side.

The Size slider changes how large the previews are.

Closing it

Click the Exit Biome Panel button, or the red cross next to Size, to return the editor to its previous view.

Finding a biome

Search, Categories and Favorites

Type in the Search box to filter biomes by name.

The Categories list sorts them by type, such as Forest or Meadow. Each installed pack has its own folder.

Click a biome's star to mark it, then pick Favorites to see only your starred biomes. Favorites are kept between sessions.

Use the refresh arrows after installing or exporting a biome.

Importing

A whole biome

Click a biome's name to add all of its layers to your emitter. They are grouped under the biome's name, so you can hide, duplicate, or adjust the whole biome at once, or change single layers. See Group Scattering.

Importing the same biome again reuses the plants already in your file.

Single layers

To take just one layer, click the arrow next to a biome's name to show its Individual Layers, then click the + button next to the one you want.

Single layers are not grouped, which makes it easy to mix layers from different biomes.

Large biomes

The Large Biome Import prompt

When a biome would create more than 100,000 instances, ScatterFlow asks how to handle it in the viewport.

The Yes, use adaptive safety button imports the layers hidden and lowers their viewport density. Renders are not affected. Turn the layers on when you are ready to see them.

The No, keep full viewport density button imports the biome as it is. Choose this if your computer can handle it.

Nothing visible after importing? Adaptive safety starts the layers hidden. Turn them on with a layer's monitor icon or the group's eye icon. If they look too sparse, raise Viewport Density in Optimization.

Your own biomes

Save your scatter setups as biomes to reuse them in other files.

Export Biome

Choose Export Biome from the arrow menu below the System List. It saves every layer on the emitter, with its settings and groups, as a .flow file.

In the export window, the Name and Category fields set how the biome is listed in the Biome Browser. The Partner field can be left empty. Preview Image is an optional picture for the thumbnail.

Save the file inside your biome folder so the Biome Browser can find it, then refresh the browser.

Use assets from your asset libraries. A biome file does not contain models; it points to them in your asset libraries. If a layer uses an object from somewhere else, the export stops and lists those objects. Replace them with library assets, or add them to a library, then export again.

GScatter environments

ScatterFlow can import GScatter environments (.gscatter files) as biomes, without the GScatter add-on. They become ordinary ScatterFlow layers that you can edit like any other.

Where to get GScatter environments

GScatter environments are available from the GScatter store at store.gscatter.com. Keep your downloads so you can reinstall them later.

Check each environment's licence before using it commercially.

Use environments, not single plants. A .gscatter file with only a plant has no layers to import as a biome.

Installing a .gscatter file

Install .gscatter files the same way as biome packs, with the Install biome packs button. A biome folder needs to be set first; see Install the biomes.

Large files can take a moment to install. You can keep working in Blender in the meantime, and Esc cancels.

Importing a GScatter environment

Installed environments are listed under GScatter in the Biome Browser's categories. Import them like any other biome: click the name for the whole environment, or add single layers from its Individual Layers list.

Each GScatter scatter system becomes one ScatterFlow layer. Large environments get the same prompt as other large biomes.

What carries over, and what is approximated

ScatterFlow converts GScatter's effects to the closest ScatterFlow settings, so the result looks like the original but may not match it exactly.

Carried over: plants, density, seed, scale, rotation, and surface alignment.

Approximated: noise masks, since several GScatter masks become one.

Not imported: the GScatter terrain generator, and effects that ScatterFlow has no equivalent for.

After importing, the layers no longer need GScatter.

When something goes wrong

Install biome packs is greyed out. Set a biome folder first.

The file will not install. The download is probably damaged or incomplete. Download it again.

The environment is not in the Biome Browser. Refresh the browser and check the GScatter category. Make sure the file is an environment, not a single plant.

Some layers are missing after importing. Their plants were not found. Install the file again. If the environment uses another GScatter product, install that one too.

Nothing happens when importing. Choose an emitter at the top of the ScatterFlow panel first.

The scene is slow. GScatter environments can be dense. Try a smaller emitter, accept adaptive safety, or lower the density of the heaviest layers. See Optimization.
