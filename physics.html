ScatterFlow documentation / Physics tab

Physics

Arrange objects with collisions, then convert the settled result into a scatter layer

Sources Quick Physics Start Scattering Area Precision Push, Grab and Move Array Collection list Convert to Scatter Advanced Settings

The Physics tab uses simulated falling and collisions to place objects. Use it for arrangements such as rolling barrels, stacked tyres, or rocks settled into corners that would be time-consuming to position individually.

You can add physics to existing objects or place new objects with brushes that simulate them as you work.

Sources

Placement brushes use objects from a Source Collection in the current file.

Source Collection

Source Collection: selects the available assets. For example, a Debris collection can contain barrels, tyres, and rocks.

Arrow: expands the collection's object list.

Tick boxes: enable or exclude individual objects from new placements. Disable an asset temporarily without removing it from the collection.

All and None: enable or disable every listed object.

+: adds selected scene objects or Asset Browser assets to the source collection.

Keep the source objects in the scene. The brushes place copies of them. Move the originals out of the camera's view rather than deleting them.

Quick Physics

These four controls apply to selected objects, including objects you have positioned manually.

Set Passive and Add Physics

Set Passive: makes objects participate in collisions without moving. Apply it to the ground, walls, ramps, and other supporting surfaces before dropping objects onto them.

Add Physics: enables simulated falling and collisions on the selection. Apply it to the objects you want to move, then play the timeline.

Objects falling through the floor? Select the floor and apply Set Passive so it can receive collisions.

Freeze and Remove

Freeze: holds selected objects at their current positions while keeping them solid for collisions.

Use Freeze to lock a completed part of a pile before adding more objects. Newly dropped objects can still land on the frozen ones.

Remove: removes physics and leaves the objects at their settled positions as ordinary scene objects.

Start Scattering

The placement brushes are called modes. They use the Source Collection and simulate objects live without requiring timeline playback.

The dials

Click Start Scattering to display six mode dials on the left of the viewport. The button changes to Stop Scattering while the controls are active.

Click a mode or press its number, 1–6, to display its settings. A shortcut card appears in the lower-left corner.

Drag a setting dial horizontally to adjust it. Click an On/Off dial to toggle it.

Press Esc or right-click to leave the active mode and return to the mode list. Press Esc again, or click Stop Scattering, to close the controls.

The modes are Area, Precision, Push, Array, Grab, and Move.

1 Area

Hold the left mouse button to place objects within the brush circle. Objects continue spawning while the button is held.

Pouring objects in

Hold the cursor in one place to build a pile, or drag to distribute objects along a path. They fall and settle as they are added.

Use short presses for controlled placement. A long press can generate many objects quickly.

Count

Sets the number of objects added at each brush step. For example, Count 6 adds six objects per step instead of one at Count 1, producing a denser result over the same press duration.

Radius

Sets the area within which objects appear. A radius of 0.6 creates a compact pile, while 2.5 spreads the same number over a wider region. Hold F and move the mouse to adjust it interactively.

Scale Min and Scale Max

Define the random size range. Set both to 1 to preserve every source object's size. A range of 0.4–2.0 produces a mix of smaller and larger copies.

Height Offset

Sets how far above the target surface objects spawn. At 0 they are placed at the ground; a value of 4 drops them from above, allowing more falling, bouncing, and rolling before they settle.

Align to Surface tilts the brush circle to match the surface beneath it.

Random Rotation

When disabled, objects spawn upright. Enable it to start each object at a random orientation, allowing it to settle on a different side or end.

Erasing and Randomize

Hold Ctrl and drag to remove objects under the brush.

Randomize generates a new variation for objects placed by the brushes. Randomize Selected limits that action to the current selection.

2 Precision

One object at a time

Click to place one object under the cursor.

Q, or the Next Asset dial, selects the next object in the Source Collection.

Shift + click places another copy of the same object.

Scale Min, Scale Max, Height Offset, Align to Surface, and Random Rotation work as they do in Area mode.

Skip Rigid Body places objects without physics. They remain where you put them, including when Height Offset places them above the ground.

Hold Ctrl and drag to erase. Use F to adjust the eraser radius.

3 Push, 5 Grab and 6 Move

Use these modes to rearrange objects already placed in the scene.

Push

Hold the left mouse button and drag to move a plane through the objects, pushing them like a broom.

Push Width sets the plane's width. A value of 0.8 affects a narrow strip; 3.0 covers a broader area. Hold F and move the mouse to adjust it.

Grab: attract

Hold the left mouse button to pull objects inside the brush toward its centre. Drag to carry them together, useful for gathering scattered objects into a pile.

Grab Radius sets the affected area.

Strength: negative values attract objects.

Grab: repel

Positive Strength pushes objects away from the brush centre. Increase it gradually for a stronger push rather than starting with a large value.

Damping reduces object motion. Lower values allow objects to travel further after being pushed.

Adjust Strength gradually. High positive values can throw objects a long distance.

Move

Click and drag an object to reposition it. Release the mouse button to return it to the simulation at its new location.

4 Array

Rows, stacks and rings

Array repeats one object in a regular pattern, such as stacked crates, a pallet of blocks, or a ring of tyres. Its settings appear in the sidebar under Modes rather than on dials.

1. Select the source object and choose Array.

2. Click Add Array.

Array Type: choose Grid for rows and stacks or Radial for rings.

Count: Grid uses X Count, Y Count, and Z Count. Radial uses Radial Count around each ring, Radial Rings for the number of rings, and Z Count for vertical layers.

Spacing: sets the gaps along each grid axis. Radial arrangements use Ring Spacing and Start Radius.

Scale: Base Scale sets overall size, while Random Scale Min and Max add variation.

Rotation: Base Rotation sets the starting orientation, and Random Rotation adds variation.

Advanced: Realize Instances converts the generated instances into geometry.

Collection list

Select and hide by group

ScatterFlow organizes physics objects into collections listed under Sources, with a count for each:

Quick Spawn: objects placed with the brushes.
Active Rigid Bodies: objects assigned physics with Add Physics.
Passive Rigid Bodies: objects assigned Set Passive, such as the ground.
Frozen Objects: objects held in place with Freeze.

Arrow: selects every object in the collection for actions such as Freeze, Remove, or Randomize Selected.

Eye: toggles collection visibility.

Convert to Scatter

From loose objects to a scatter layer

Convert to Scatter replaces placed objects with instances in a layer named Physics Scatter. It preserves their positions, rotations, and scales while reducing the overhead of many separate objects.

1. Select an Emitter in the Scatter tab. The new layer needs an emitter to belong to.

2. Click Convert to Scatter and confirm.

Physics Scatter appears in the System List as a Manual layer. You can continue refining its instances with the Manual Mode brushes.

To convert only part of the arrangement, select those objects before running the command.

Conversion ends their physics simulation. Finish settling and rearranging the objects before converting them.

Advanced Settings

Collision Settings

Control how objects respond when they contact one another.

Collision Type: the shape used for collision calculations. Convex Hull approximates the outer shape and suits many objects. Box, Sphere, Capsule, and Cylinder are simpler options with lower processing cost. Mesh follows the surface more closely, useful for hollow objects that other objects need to enter.

Friction: resistance to sliding. Lower values allow surfaces to slide more freely.

Bounce: how strongly objects rebound after contact. Increase it for more bounce or reduce it for less.

Collision Margin: an additional collision boundary around the object.

Rolling and Spinning: resistance to those types of motion. Increase Rolling to help barrels settle rather than continue rolling.

Friction Anchor: helps stabilize stacks that gradually slide apart.

Set as Default: uses the current values for objects assigned physics afterward.

Apply to Selected: applies the values to selected objects.

Contact behaviour depends on both surfaces. Apply Bounce and Friction settings to the ground as well as to falling objects.

Split Impulse, PyBullet Solver and Origin Tools

Split Impulse reduces the tendency of initially overlapping objects to be pushed violently apart. Leave Enable Split Impulse enabled. Rigid Body Cache defines the frame range for timeline-based simulation.

PyBullet Solver balances accuracy and processing cost. Increase Iterations and Substeps when small or fast objects pass through surfaces or stacks remain unstable. Other solver controls provide finer adjustments for difficult contacts.

Origin Tools: Center of Mass (Vol) moves object origins to their volume-based centre of mass for more natural tumbling. Bottom Center places origins at the centre of each base for easier surface placement.
