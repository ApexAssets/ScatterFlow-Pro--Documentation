ScatterFlow documentation / Physics tab

Physics

Arrange objects with collisions, then convert the settled result into a scatter layer

Sources Quick Physics Start Scattering Area Precision Push, Grab and Move Array Collection list Convert to Scatter Advanced Settings

The Physics tab places objects by letting them fall and collide. Use it for things like rolling barrels, stacked tyres, or rocks settled into corners, which would be slow to place by hand.

You can add physics to objects already in your scene, or place new ones with brushes that simulate them as you go.

Sources

Placement brushes use objects from a Source Collection in the current file.

Source Collection

The Source Collection field sets which objects the brushes can place, such as a collection of barrels, tyres, and rocks.

The Arrow expands the list of objects. Use the Tick boxes to leave an object out of new placements without removing it from the collection. The All and None buttons tick or untick everything.

The + button adds the selected scene objects or Asset Browser assets to the collection.

Keep the source objects in the scene. The brushes place copies of them, so move the originals out of the camera's view instead of deleting them.

Quick Physics

These controls work on the selected objects, including ones you placed yourself.

Set Passive and Add Physics

The Set Passive button makes objects solid without letting them move. Use it on the ground, walls, ramps, and anything else objects should land on.

The Add Physics button makes the selected objects fall and collide. Use it on the objects you want to move, then play the timeline.

Objects falling through the floor? Select the floor and apply Set Passive so it can receive collisions.

Freeze and Remove

The Freeze button holds the selected objects where they are, but keeps them solid. Use it to lock part of a pile before adding more. New objects can still land on frozen ones.

The Remove button takes the physics off and leaves the objects where they settled, as ordinary objects.

Start Scattering

The placement brushes are called modes. They use the Source Collection and simulate objects live, without playing the timeline.

The dials

Click Start Scattering to show the mode dials in the viewport. Pick a mode by clicking it or pressing its number, 1–6.

Drag a setting dial sideways to change it. Click an On/Off dial to toggle it.

Press Esc or right-click to go back to the mode list. Press Esc again, or click Stop Scattering, to close the controls.

The modes are Area, Precision, Push, Array, Grab, and Move.

1 Area

Hold the left mouse button to place objects inside the brush circle. Objects keep spawning for as long as you hold it.

Pouring objects in

Hold still to build a pile, or drag to spread objects along a path. They fall and settle as they are added.

Use short presses for controlled placement. A long press can add a lot of objects quickly.

Count

Sets how many objects each brush step adds. Higher values give a denser result in the same time.

Radius

Sets the size of the area objects appear in. A small radius makes a tight pile; a large one spreads the same objects wider. Hold F and move the mouse to change it.

Scale Min and Scale Max

Set the range of random sizes. Set both to 1 to keep every object at its original size.

Height Offset

Sets how high above the surface objects spawn. At 0 they start on the ground. Higher values drop them from above, so they fall, bounce, and roll more before settling.

Turn on Align to Surface to tilt the brush circle to match the surface under it.

Random Rotation

When it is off, objects spawn upright. Turn it on to start each one at a random angle, so they settle on different sides.

Erasing and Randomize

Hold Ctrl and drag to remove objects under the brush.

Click the Randomize dial to give the objects placed by the brushes a new variation. The Randomize Selected dial does the same for the selected objects only.

2 Precision

One object at a time

Click to place one object at the cursor. Press Q, or use the Next Asset dial, to switch to the next object in the Source Collection. Shift + click places another copy of the same object.

Scale Min, Scale Max, Height Offset, Align to Surface, and Random Rotation work as in Area mode.

Turn on Skip Rigid Body to place objects without physics, so they stay exactly where you put them, even above the ground with Height Offset.

Hold Ctrl and drag to erase, and use F to resize the eraser.

3 Push, 5 Grab and 6 Move

Use these modes to rearrange objects already placed in the scene.

Push

Drag with the left mouse button to sweep objects along, like a broom.

Push Width sets how wide the sweep is. Hold F and move the mouse to change it.

Grab: attract

Hold the left mouse button to pull objects toward the centre of the brush, and drag to carry them along. Use it to gather scattered objects into a pile.

Grab Radius sets the area affected. Negative Strength values attract objects.

Grab: repel

Positive Strength values push objects away from the centre of the brush.

Damping slows objects down. Lower values let them travel further after a push.

Adjust Strength gradually. High positive values can throw objects a long way.

Move

Drag an object to move it. When you let go, it rejoins the simulation at its new spot.

4 Array

Rows, stacks and rings

Array repeats one object in a regular pattern, such as stacked crates or a ring of tyres. Its settings are in the sidebar under Modes, not on dials.

Select the source object, choose the Array mode, and click Add Array.

Set Array Type to Grid for rows and stacks, or Radial for rings.

In the Count panel, Grid uses X Count, Y Count, and Z Count. Radial uses Radial Count for objects per ring, Radial Rings for the number of rings, and Z Count for layers.

The Spacing panel sets the gaps along each grid axis. Radial uses Ring Spacing and Start Radius instead.

In the Scale and Rotation panels, Base Scale and Base Rotation set the starting size and angle. Random Scale Min, Max, and Random Rotation add variation.

In the Advanced panel, Realize Instances turns the instances into real geometry.

Collection list

Select and hide by group

ScatterFlow sorts physics objects into collections, listed under Sources with a count for each:

Quick Spawn: placed with the brushes.
Active Rigid Bodies: given Add Physics.
Passive Rigid Bodies: given Set Passive, such as the ground.
Frozen Objects: held in place with Freeze.

Click a collection's Arrow to select everything in it, for example before Freeze, Remove, or Randomize Selected. The Eye icon shows or hides the collection.

Convert to Scatter

From loose objects to a scatter layer

The Convert to Scatter button turns your placed objects into instances on a new layer called Physics Scatter. They keep their positions, rotations, and sizes, and your scene is lighter than with many separate objects.

Select an Emitter in the Scatter tab first, since the new layer needs one to belong to. Then click Convert to Scatter and confirm. To convert only part of the arrangement, select those objects first.

The new layer is a Manual layer, so you can keep refining it with the Manual Mode brushes.

Conversion ends their physics simulation. Finish settling and arranging the objects before you convert them.

Advanced Settings

Collision Settings

These settings control how objects behave when they touch.

The Collision Type menu sets the shape used for collisions. Convex Hull follows the outer shape and suits many objects. Box, Sphere, Capsule, and Cylinder are simpler and lighter. Mesh follows the surface closely; use it for hollow objects that other objects need to fall into.

Friction is resistance to sliding; lower values let objects slide more. Bounce sets how much objects rebound when they hit something.

Collision Margin adds an extra collision boundary around each object.

Rolling and Spinning resist those motions. Raise Rolling to help barrels settle instead of rolling on. Friction Anchor helps steady stacks that slowly slide apart.

The Set as Default button uses the current values for objects you add physics to later. The Apply to Selected button applies them to the selected objects.

Contact behaviour depends on both surfaces. Set Bounce and Friction on the ground as well as on the falling objects.

Split Impulse, PyBullet Solver and Origin Tools

Split Impulse stops objects that start out overlapping from being thrown violently apart. Leave the Enable Split Impulse checkbox on. Rigid Body Cache sets the frame range when you simulate on the timeline.

The settings in the PyBullet Solver section trade accuracy against speed. Raise Iterations and Substeps if small or fast objects pass through surfaces, or if stacks will not stay still. The other solver controls fine-tune difficult contacts.

In the Origin Tools section, the Center of Mass (Vol) button moves each origin to the object's centre of mass, so it tumbles more naturally. The Bottom Center button puts origins at the centre of each object's base, which makes placing them on surfaces easier.
