Culling and Proximity

Control placement with painted masks, nearby objects, and curves

Culling Geometry Proximity Curve Proximity

Culling: Vertex Group

Paint a vertex group on the scatter surface to choose where a layer appears. Instances stay in painted areas and are removed everywhere else.

Vertex Group

  • Default off

Turn on Vertex Group and pick a group. You can keep several groups and switch between them to try different layouts.

The list shows the vertex groups on the layer's surface: its emitter, or its Single Surface object.

Mask detail depends on the surface mesh. Weights are stored per vertex, so a coarse mesh gives a rough edge. Subdivide the area when you need finer control.

Painting the mask

Select the surface object and click the brush button at the end of the row to start weight painting. Paint where the layer should appear.

Click the button again to go back to Object Mode.

Smooth Transition

  • Default off
  • Transition 1.0

Without Smooth Transition, instances are either kept or removed. With it on, instances get smaller where the paint is lighter, so the edge of the mask fades out.

Transition sets how much paint an instance needs to reach full size. Lower values reach full size in lightly painted areas. Higher values need heavier paint.

Invert

  • Default off

Reverses the mask, so the layer appears outside the painted area. The arrow button next to the vertex group field does the same.

This lets one mask serve several layers. For example, paint a path, use it as it is for gravel or flowers, and invert it on a tree layer to keep trees off the path.

Geometry Proximity

Use nearby objects to keep a layer away from them, or only close to them. For example, clear space around boulders, or grow plants along walls and around tree stumps.

Object and Distance

  • Default off
  • Distance 0 m

Turn on Geometry Proximity, pick an object in the Object field, and set a Distance. By default, instances within that distance are removed.

Distance is measured from the object's surface, not its centre, so the cleared area follows its shape.

Smooth Transition

  • Default off
  • Transition 1 m

Softens the edge of the cleared area. Instances grow from nothing at the Distance edge to full size Transition metres further out.

Behaviour

  • Default Avoid

Set Behaviour to Avoid to remove instances within the Distance of the object.

Set it to Seek to keep instances only within that Distance. Use it to gather plants around something, such as weeds at the foot of a wall or ferns around a stump.

Type: Single Object or Multiple Objects

  • Default Single Object

Set Type to Single Object to use one object. Set it to Multiple Objects to use a collection instead, which applies the same settings to every object in it.

Curve Proximity

Use a curve to shape a path, road, stream, fence line, or any other long boundary. The scatter updates as you edit the curve.

Curve and Distance

  • Default off
  • Distance 1 m

Turn on Curve Proximity and pick a curve in the Curve field. With Avoid, Distance is the clearance on each side of the curve, so set it to half the width of your path.

Smooth Transition

  • Default off
  • Transition 2

Fades the edge of the path. Instances grow to full size over the Transition distance instead of stopping abruptly.

Infinite Z

  • Default off

Distance is normally measured in 3D. If the curve sits too far above the terrain, its effect weakens or disappears, and the path can close up.

Turn on Infinite Z to ignore height, so the curve affects the ground directly below it. This lets you shape a path on uneven terrain with a flat curve above the ground.

Behaviour

  • Default Avoid

Set Behaviour to Avoid to clear instances along the curve. Set it to Seek to keep them only near the curve, which suits hedges, tree-lined avenues, or reeds along a stream.

Type: Single Curve or Multiple Curves

  • Default Single Curve

Set Type to Single Curve to use one curve. Set it to Multiple Curves to use a collection, so one set of settings can control a whole network of paths.
