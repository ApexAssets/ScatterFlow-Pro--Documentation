Culling and Proximity

Control placement with painted masks, nearby objects, and curves

Culling Geometry Proximity Curve Proximity

Culling: Vertex Group

Use a vertex group on the scatter surface to define where instances appear. The layer is kept in painted areas and excluded from unpainted areas.

Vertex Group

  • Default off

Enable Vertex Group and select a group from the field. Use different groups to switch between layouts such as a winding strip or isolated groves.

The picker shows vertex groups from the surface the layer uses: its emitter or its Single Surface object.

Mask detail depends on the surface mesh. Weights are stored per vertex. A coarse mesh produces a less detailed boundary; subdivide the relevant area when you need finer control.

Painting the mask

Select the surface object, then click the brush button at the end of the row to enter Weight Paint mode. Paint the areas where the layer should appear.

Click the button again to return to Object Mode and view the updated scatter.

Smooth Transition

  • Default off
  • Transition 1.0

Without Smooth Transition, instances are either kept or excluded. With it enabled, instance scale follows the painted weight, creating smaller instances near the mask boundary.

Transition sets the weight needed for full-size instances. Lower values reach full size in lightly painted areas; higher values require stronger weights.

Invert

  • Default off

Reverses the mask so the layer appears outside the painted area. The arrow button beside the vertex group field performs the same action.

For example, paint a path once, use the mask normally for gravel or flowers, and invert it on a tree layer to keep trees off the path.

Geometry Proximity

Use nearby objects to exclude a layer from an area or restrict it to that area. This is useful for clear space around boulders, vegetation near walls, or plants around tree stumps.

Object and Distance

  • Default off
  • Distance 0 m

Enable Geometry Proximity, choose an Object, and set Distance. With the default Avoid behaviour, instances within that distance are removed.

Distance is measured from the object's surface rather than its centre, so the cleared area follows its shape.

Smooth Transition

  • Default off
  • Transition 1 m

Softens the boundary around the excluded area. Instances grow from zero size at the Distance boundary to full size Transition metres further away.

Behaviour

  • Default Avoid

Avoid excludes instances within the specified Distance of the object.

Seek keeps instances only within that Distance. Use it to concentrate vegetation around a target, such as weeds at the base of a wall or ferns around a stump.

Type: Single Object or Multiple Objects

  • Default Single Object

Single Object uses one target. Multiple Objects replaces the object field with a collection picker and applies the same settings to every object in that collection.

Curve Proximity

Use a curve to define a path, road, stream, fence line, or other continuous boundary. The scatter responds when you edit the curve.

Curve and Distance

  • Default off
  • Distance 1 m

Enable Curve Proximity and select a Curve. With Avoid behaviour, Distance sets the clearance on each side, so use half your intended path width.

Smooth Transition

  • Default off
  • Transition 2

Creates a gradual boundary along the path. Instances increase to full size over the Transition distance rather than ending abruptly.

Infinite Z

  • Default off

By default, distance is measured in 3D. Moving a curve far enough above the terrain can reduce or remove its effect. This can close the cleared path even though the curve has not moved sideways.

Enable Infinite Z to ignore height and apply the curve's influence vertically to the terrain below. Use it to control a path on uneven terrain with a flat curve positioned above the ground.

Behaviour

  • Default Avoid

Avoid clears instances along the curve. Seek keeps them only near the curve, useful for hedges, avenues of trees, or reeds beside a stream.

Type: Single Curve or Multiple Curves

  • Default Single Curve

Single Curve uses one curve object. Multiple Curves uses a collection, allowing one set of proximity settings to control an entire path network.
